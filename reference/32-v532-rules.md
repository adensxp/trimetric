## 四、行业 beta 风险维度

```python
INDUSTRY_BETA = {
    # 高 beta（>=1.3）：保守
    '房地产': 1.5, '建筑装饰': 1.4, '美容护理': 1.3, '建筑材料': 1.3,
    # 中高 beta
    '交通运输': 1.2, '汽车': 1.2, '机械设备': 1.1, ..., '钢铁': 1.2,
    # 中 beta
    '电子': 1.0, '计算机': 1.0, '通信': 1.0, '国防军工': 1.0, ...,
    # 低 beta：可激进
    '银行': 0.8, '非银金融': 0.9, '食品饮料': 0.9, '家用电器': 0.9,
}

# 低 beta + P39 优先行业：+0.5 分
if ind_beta <= 0.8 and p39_match:
    score += 0.5
```

**实战效果**：30 龙头中行业 beta 影响小（30 龙头主要是低 beta 的银行/食品饮料/家电 + 周期股）。
