## 20. 长线机构票分支（V5.2.0 新增·601328 交通银行复盘）

### 20.0 背景与适用范围

**问题**：V5.1.2 高量战法为"高波动 + 主力可识别 + K 线信号清晰"的中小盘成长股设计。在国有大行、价值蓝筹、低估值高股息这一类"**长线机构票**"上结构性失灵。

**失灵表现**：
- 左侧建仓（L4）因"跌幅>30%"门槛进不去（银行股极少深跌）
- 右侧信号（B1-B8）因"高量定义"过松导致信号过密，决策噪音大
- 清仓机制（C1-C6）因"低波动品种不适用 C7"反而漏判阴跌出货
- 高股息底仓保护（12.6）与高量战法规则不衔接

**解决方案**：在 V5.1.2 框架下新增"长线机构票分支规则"，对低波动 + 高股息 + 大盘股单独建立判定路径，**不替代原规则，与原有规则并列适用**。

---

### 20.1 P1·长线机构票标的识别

**触发条件（同时满足 4 条）**：

1. **流通市值 > 1000 亿**（大盘股）
2. **60 日均振幅 < 3%**（低波动）
3. **股息率 TTM > 4%**（高股息）
4. **连续分红 > 5 年**（稳定性）

**执行**：
- 标的进入"长线机构票"分支
- 后续 20.2-20.8 补丁仅适用于此类标的
- **不替代原规则**——若高量信号明确（量比 > 2.5），仍可走原战法

**适用标的示例（2026-08）**：交通银行、工商银行、农业银行、中国银行、建设银行、招商银行、长江电力等。

**与原规则的关系**：
- 标的**同时适用两套规则**——遇到矛盾时按"安全 > 收益"裁决（详见 20.9）

---

### 20.2 P2·长线机构票"高量"重定义

**问题**：原规则"当日量严格大于前 3 日任意一天"对长线机构票过松（银行股日常量能波动本就小，"前 3 日 max"频繁触发）。

**新规则**：
- 长线机构票"高量" = **当日量 ≥ 5 日均量 × 1.8**
- 普通品种仍用原规则（量 > 前 3 日 max）

**量能衰减判定**：
- 长线机构票出现"高量"后，若 T+1 缩量 > 30% 且未跌破实体低 → 视为**弱有效**（不算强高量信号）

**理由**：银行股 5 日均量稳定，放量 1.8 倍以上才是真正的异动。

**实战案例（交行 7/31）**：7/31 量 378 万手 ÷ 5 日均量 ~140 万手 = **2.7 倍** → 满足 P2 高量；但 T+1 缩量 30%+ 且未破实体低 → **弱有效**，不能算强主力入场信号。

---

### 20.3 P3·L4 破净建仓的 PB 主导

**原规则（6.1）**：股价自高点跌 > 30% 或 PB < 1（仅限资产较实行业）

**补丁规则**：
- **长线机构票**：取消"跌幅>30%"门槛，**PB < 1 即满足 L4 前提三**
- **银行/电力/高速公路等"资产较实"行业**：**PB < 0.7 自动进入 L4 候选池**
- **普通品种**：保留原规则

**执行逻辑**：

```
IF 标的属于"长线机构票" AND PB < 1:
    L4 前提三自动满足（无需跌幅 30%）
    按 L1 → L2 → L3 → L4 顺序建仓
    每跌 5% 加 5%，总仓 ≤ 20%
ELSE:
    按原规则（需跌幅 > 30%）
```

**实战案例（交行 2026-08-14）**：PB=0.53 < 1 → 满足 L4 前提三 → 可启动左侧建仓序列（L1 5% → L2 累计 10% → L3 累计 15% → L4 累计 ≤ 20%）。

### 20.4 P4·C7 "无高量大跌清仓"门槛反转

**原规则（10.4 V5.1.2）**：仅 60 日均振幅 ≥ 5% 的高波动品种适用 C7。

**补丁规则**：
- 取消"高波动"门槛——**C7 适用于所有品种**
- 阈值按 60 日均振幅分档：

| 60 日均振幅 | 品种分类 | C7 阈值 |
|------------|---------|---------|
| < 2% | 极低波动 | **1.5%** |
| 2-3% | 低波动 | **2%** |
| 3-5% | 普通 | **3%** |
| ≥ 5% | 高波动 | **5%**（原规则）|

**理由**：
- 高波动品种单日大跌通常伴随高量，已被 C1-C6 覆盖，C7 是冗余
- 低波动品种单日大跌不伴随高量才是真正的出货信号，C7 应是主战场

**与 V5.1.2 关系**：C7 触发条件放宽到所有品种（按振幅分档），但**保留"高波动品种单日大跌通常伴随高量"的实践优先级**——高波动 + 跌 5% + 非高量 = 罕见组合，逻辑上保留规则但实际触发概率低。

### 20.5 P5·高股息底仓期间的"高量处理路径"

**问题**：12.6 高股息底仓保护未定义"底仓期间出现高量如何处理"。

**新规则**（长线机构票底仓期间，已建立 6 个月以上底仓）：

| 跌幅 | 底仓 | 机动仓 |
|------|------|--------|
| < 10% | 不清 | C 类触发即清 |
| ≥ 10% | 清 | 清 |

**处理流程**：
- 出现高量 → 走左右衔接流程（步骤一至四）
- 三天定性失败时：底仓不减不清，**仅机动仓清仓**
- 机动仓触发 C3：按 C3 规则清机动仓，底仓不动
- 底仓保护豁免 C 类清仓的前提是**跌幅 < 10%**
- 跌幅 ≥ 10% 仍按 C 类清仓**全部仓位**（保护失效）

**实战案例（交行 8/4）**：
- 8/4 跌幅 -3.83% < 10% → 底仓不动
- 机动仓按 C3 清（跌幅符合 C7 低波动 2% 阈值）

**底仓/机动仓比例建议**：6:4（6 成底仓 + 4 成机动仓）

### 20.6 P6·W1 长线机构票提前减仓

**问题**：原 W1"高量首日不操作，等三天定性"——对银行股节奏过慢。

**新规则**：长线机构票出现以下任一形态时，**T+0 即可减机动仓 50%**：

| 形态 | 特征 | 信号含义 |
|------|------|---------|
| **放量滞涨** | 高量 + 实体涨幅 < 0.5% + 上影 > 实体 1.5 倍 | 高位接盘，抛压重 |
| **缺口出货** | 高量 + 跳空低开 + 实体为阴 | 主力出货缺口 |
| **无下影抛压** | 高量 + 收盘 = 当日最低价（无下影）| 单纯抛压，无承接 |

**执行**：
- **仅减机动仓 50%**（不动底仓）
- 后续 T+1-T+3 三天定性失败 → 机动仓继续按 C 类清仓
- 三天定性成功 → 视情况 S8 回补

**实战案例（交行 7/31）**：
- 形态：跳空低开（开 7.19 vs 前收 7.32）+ 几乎平收（收 7.18）+ 巨量（378 万手）+ 无下影
- 完全符合"缺口出货"形态 → **7/31 当日即可减机动仓 50%**
- 而非等 8/4（C3 触发）才清

**减仓效果对比**：

| 方案 | 执行 | 均价 | 损失 |
|------|------|------|------|
| 按原规则 | 7.18 全部清 | 7.18 | -0.14 元/股 |
| 按补丁规则 | 7.18 减 50% + 7.04 清 50% | 7.11 | -0.21 元/股 |

**取舍**：补丁保留了"提前识别主力出货"的能力，对风险规避更优（避免在更低位置清剩余 50%）。

### 20.7 P7·二次进场锁窗口期延长

**原规则（10.7）**：条件 A/B 窗口期 8 日 / 条件 C 窗口期 10 日。

**补丁规则**（仅适用于长线机构票）：

| 条件 | 原窗口期 | 长线机构票窗口期 | 延长幅度 |
|------|----------|----------------|---------|
| 条件 A | 8 日 | **12 日** | +50% |
| 条件 B | 8 日 | **12 日** | +50% |
| 条件 C | 10 日 | **15 日** | +50% |
| **冷静期** | 5 日 | 5 日（**不变**）| - |

**理由**：
- 银行股成交节奏慢，新高量出现频率低
- 8 日窗口期太短，可能错过右侧黄金买点
- 延长窗口期不增加风险（窗口外自动失效）

**与 V5.1.2 关系**：V5.1.2 把 A 从 5→8，本次对长线机构票再延长到 12。普通品种仍用 V5.1.2 的 8。

### 20.8 P8·前提一"无高量下跌"的二元区分

**原规则（3.1）**：下跌趋势中无高量 → 打死不开仓。

**补丁规则**：长线机构票区分两类"无高量下跌"：

| 形态 | 特征 | 处理 |
|------|------|------|
| **阴跌无高量** | 持续小阴线 + MACD 绿柱放量 + 跌幅累计 > 5% | **真不开仓**（原规则）|
| **缩量横盘无高量** | K 线实体小 + MACD 绿柱缩短 + PB<1 + 股息率>4% | **可走 L4 路径**（补丁 3）|

**判定指标**：

```
阴跌 = 连续 5 日日均跌幅 > 0.5% 且量能未明显萎缩
缩量横盘 = 5 日均量 < 20 日均量 × 70% + 60 日均振幅 < 3%
```

**实战案例（交行 8/4-8/13）**：
- 5 日均量 126 万 < 20 日均量 ~200 万 × 70% = 140 万 ✓
- 60 日均振幅 2.12% < 3% ✓
- → 判定为"缩量横盘" → 可走 L4 路径 ✓

### 20.9 补丁与原规则的裁决优先级

**总原则**：
1. **补丁仅适用于"长线机构票"标的**（20.1 识别）
2. **补丁不替代原规则**——若原规则信号更明确，**优先执行原规则**
3. **补丁与原规则冲突时**，按"安全 > 收益"原则裁决
4. 同一标的**两套规则并行适用**，遇到信号矛盾时：
   - 安全侧（清仓/减仓）取**从严**
   - 收益侧（加仓/建仓）取**从稳**

**裁决对照表**：

| 场景 | 原规则 | 补丁 | 裁决 |
|------|--------|------|------|
| 长线机构票 + 高量明确（量比 > 2.5）| 加仓/建仓 | 不触发 | 走原规则 |
| 长线机构票 + 缩量横盘 + PB<1 | 不可 L4（跌幅不够）| 可启动 L1 | 走补丁 |
| 长线机构票 + 跌 2%（低波动）| C7 不触发 | C7 触发 | 走补丁 |
| 长线机构票 + 跌 5%（高波动）| C7 触发 | C7 触发 | 走原规则 |
| 长线机构票 + 底仓 + 跌 3% | 触发 C3 | 仅清机动仓 | 走补丁（底仓不动）|

### 20.10 长线机构票决策流程（应用补丁后）

1. **标的识别（20.1）**：是否同时满足 4 条？→ 是 → 进入长线机构票分支
2. **前提一·二元化（20.8）**：阴跌还是缩量横盘？
   - 阴跌 → 走原规则（不开仓）
   - 缩量横盘 + PB<1 → 走 L4 路径
3. **大盘风险（3.2）**：是否解除？
4. **双引擎（3.3）**：股息率/PE 极低分位 → 提升两档
5. **L1 启动（20.3）**：PB<1 → 启动 L1 缩量止跌
6. **L1-L4 序列**：每跌 5% 加 5%，总仓 ≤ 20%
7. **高量出现（20.2）**：P2 高量 = 量 ≥ 5 日均量 × 1.8
8. **提前减仓判定（20.6）**：是否出现放量滞涨/缺口出货/无下影？→ 是 → T+0 减机动仓 50%
9. **三天定性**：定性成功 → 走 B 类加仓；失败 → 机动仓清仓
10. **清仓信号（C1-C7）**：C7 按 20.4 振幅分档阈值
11. **底仓保护（20.5）**：跌幅 < 10% → 底仓不动
12. **二次进场锁（20.7）**：窗口期延长 50%

### 20.11 风险提示

1. **补丁未经过多标的、多周期复盘**——本补丁基于交通银行单标的单时点分析，实战有效性待验证
2. **补丁与原规则的协调可能存在遗漏场景**——建议小仓位试运行 3-6 个月后再扩大
3. **长线机构票的定义阈值**（补丁 1）需要根据市场环境调整
4. **C7 门槛反转**（补丁 4）可能让低波动品种清仓信号过密，需配合补丁 2 的"高量重定义"使用
5. **底仓期间高量处理**（补丁 5）需要用户明确"底仓"和"机动仓"的比例，建议 **6:4**
