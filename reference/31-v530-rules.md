# V5.3.0 三大新规则（P37 升级 / P42 周期股配套 / P44 门槛）

> **版本**: V5.3.0 新增（2026-08-18）
> **驱动案例**: V5.2.9.2 在 2025-08-18 普通震荡市反输 V5.2.8 -20pp
> **核心**: 解决 V5.2.9.2 P40v2 过度激进 + P42 龙头无差别加分

## 一、V5.3.0 升级原因

V5.2.9.2 在 3 特殊起点（2023-08 大底/2024-09 牛顶/2025-04 震荡）回测 +11.7pp，但：
- **2025-08-18 真实时点**（普通震荡市）V5.2.9.2 长周期 1 年反输 V5.2.8 -20pp
- 根因：P40v2 把"行业不极端下行 + 龙头 + 估值不算贵"当作"强触底"过度升级
- 结果：价值股龙头（美的/茅台/平安/恒瑞/欧派/分众等）被升级到"买入"，1 年后多数跌 -1% 到 -33%

## 二、P37 升级：市场状态过滤器

### 规则定义

```python
# 取沪深 300 60 日表现
def get_market_state(date):
    hs300_now = ...  # 当前收盘价
    hs300_60 = ...   # 60 日前收盘价
    ret_60d = (hs300_now - hs300_60) / hs300_60 * 100
    
    if ret_60d > +15: return '强牛'
    elif ret_60d < -15: return '强熊'
    else: return '震荡'
```

### 应用

```python
# 强牛：不升级 P40v2（避免追高）
if market_state == '强牛':
    # "买入"→"持有"；"持有"→"减仓"
    _downgrade_in_bull(decision)

# 强熊：全升级 P40v2（抄底）
elif market_state == '强熊':
    # "减仓"→"持有"；"持有"→"买入"；"买入"→"强买"
    _upgrade_in_bear(decision)
```

## 四、P44 长周期升级门槛

### 规则定义

```python
# 行业 PE 历史分位（5 年）
def get_industry_pe_percentile(ind, date):
    cur_pe = ...  # 当前行业 PE 中位
    historical_pes = ...  # 5 年历史 PE 列表
    rank = sum(1 for hpe in historical_pes if hpe <= cur_pe)
    return rank / len(historical_pes) * 100  # 0-100

# 长周期升级门槛
if cycle == '长':
    if ind_pe_pct < 30:  # PE 历史分位 < 30% 才升级

        pass
```
