# P42 - 行业龙头识别

> **版本**: V5.2.9 新增
> **优先级**: P2
> **驱动案例**: 30 行业龙头回测（错失主升浪）

## 一、问题背景

**V5.2.8 缺失**：
- 没用 `rank_in_industry` 字段
- 行业龙头 = Top 1/2/3 没特殊处理
- 导致"龙头 + 行业下行"被一律卖出

**实战问题**：
- 紫金矿业（有色 Top 1）3 年 +187.8% 错失
- 中国铝业（有色 Top 2）3 年 +123% 错失
- 工商银行（银行 Top 1）3 年 +87.6% 错失

## 二、规则定义

### 龙头加分

```python
# 取 rank_in_industry 字段
IF rank_in_industry == 1:
    leader_bonus = +1.5  # 绝对龙头
ELIF rank_in_industry in (2, 3):
    leader_bonus = +0.5  # 次龙头
ELSE:
    leader_bonus = 0
```

### 应用场景

P42 在以下规则中应用：
- **P40v2 行业下行分级**：龙头可升级到"持有"或"买入"
- **P41 周期股反向**：龙头加分
- **总评分系统**：P42 加分影响最终决策组

## 四、为什么龙头重要

### 龙头股的稳定性

| 维度 | 龙头 | 非龙头 |
|------|------|--------|
| 抗跌性 | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| 主升浪涨幅 | +50% ~ +200% | +10% ~ +30% |
| 行业下行表现 | 跌得少 | 跌得多 |
| 反弹力度 | 强 | 弱 |
| 资金抱团 | 持续 | 短暂 |

### 龙头识别 + 行业下行 = 触底信号

```
行业下行 -5% + Top 3 龙头 = 主升浪前夜
行业下行 -5% + 非龙头 = 应该卖出
```

## 六、注意事项

1. **Top 1 优先**：Top 1 比 Top 2/3 更强
2. **跨行业龙头不通用**：每个行业有自己的龙头
3. **龙头不总是买**：行业恶化时龙头也跌
4. **P42 是加分项，不是决定项**：必须配合 P40v2 / P41 / P43

## 七、配套规则

- **P40v2 行业下行分级**：P42 决定是否进入"减仓"或"持有"
- **P41 周期股反向**：P42 是 P41 加分项之一
- **P43 估值底部**：P42 配合 P43 触发"强触底"
- **P44 三周期操作**：长周期 P42 加分升级决策
