# P25 · 股东户数变化信号（ShareholderNum · V5.2.4 新增）

> **背景**：V5.2.3 实战中际旭创暴露——**C3 触发时仅看 K 线无法判断筹码集中度**。8-10 触发 C3 时，如果知道 2026-Q1 股东户数 -15.8%，就能预判"主力在低位回补筹码 → C3 假破位概率高"。
>
> **数据源**：恒生 `ShareholderNum`（股东总户数、增减、平均持股、前十大股东持股比例）

---

## 25.1 股东户数基础

股东户数 = 持有该股的账户数（按季度披露）

- **户数下降** = 筹码集中 = 主力在低位接盘 = 拉升前兆
- **户数增加** = 筹码分散 = 主力在高位派发 = 见顶信号
- **前十大股东持股比例**反映机构集中度

---

## 25.2 户数变化阈值

| 季度户数变化 | 解读 | 信号 |
|-------------|------|------|
| **< -10%** | **大幅集中** | 主力回补 |
| -10% ~ -3% | 中度集中 | 标准 |
| -3% ~ +3% | 持平 | 中性 |
| +3% ~ +10% | 轻度分散 | 派发初期 |
| **> +10%** | **大幅分散** | **顶部派发嫌疑** |

> **关键阈值 ±10%**：
> - 下降 > 10% = 主力回补
> - 上升 > 10% = 派发信号

---

## 25.3 P25 实战判定

### 25.3.1 与 C3 的关系

```
IF C3 触发 AND 上一季度户数下降 > 10%:
    P25 = "主力低位回补"
    C3 假破位概率高 → 启动 P21 v2 宽容模式验证
    
IF C3 触发 AND 上一季度户数上升 > 10%:
    P25 = "高位派发后破位"
    C3 真破位概率高 → 严格清仓
    
IF C3 触发 AND 户数持平:
    P25 = "中性"
    按规则默认处理
```

### 25.3.2 与加仓信号的关系

```
IF B 类信号触发 AND 户数持续下降（2 季度累计 < -15%）:
    加仓信号提一档
    原因：筹码集中 + 技术信号 = 强主力进攻
    
IF B 类信号触发 AND 户数持续上升（2 季度累计 > +15%）:
    加仓信号降一档
    原因：筹码分散 = 拉高出货嫌疑
```

### 25.3.3 与 B8 极强趋势的关系

B8 触发时如果 P25 = "大幅集中"（2 季度累计 < -20%），**加倍仓位上限**：
- 标准 40% → 50%
- 高股息 70% → 80%
- 二级长线 50% → 60%

## 25.4 P25 实战案例（中际旭创 300308）

### 历史户数变化

| 季度 | 户数 | 变化 | 解读 |
|------|------|------|------|
| 2024-03 | 72,919 | - | 起点 |
| 2024-06 | 68,996 | **-5.4%** | 集中 |
| 2024-09 | 79,334 | **+15.0%** | 派发 |
| 2024-12 | 136,277 | **+71.8%** | **顶部派发** |
| 2025-03 | 193,664 | **+42.1%** | 持续派发 |
| 2025-06 | 128,344 | **-33.7%** | **大幅集中**（启动拉升）|
| 2025-09 | 132,336 | +3.1% | 持平 |
| 2025-12 | 140,370 | +6.1% | 轻微派发 |
| 2026-02 | 183,356 | **+30.6%** | **大幅派发**（8-04 高位对应）|
| 2026-03 | 154,418 | **-15.8%** | **大幅集中**（8-11 后启动）|

### 实战应用

**8-04 高位 +13.24% 行情**：
- 当时最新户数 = 2025-12 户数 140,370
- 季增 +6.1% → **未达 +10% 派发阈值**
- P25 = "中性" → 不影响 8-04 高量判定

**8-10 C3 触发时**：
- 当时最新户数 = 2025-12 户数（2026-03 公告在 4-17 才出）
- **P25 无法实时获取**（季度披露滞后 30-45 日）
- 8-11~8-14 行情后，**回看 2026-03 户数 -15.8%** = **大幅集中 = 假破位验证**

### P25 实时性问题

**P25 实战限制**：
- 户数**季度披露**，滞后 30-45 日
- C3 触发时**不能实时获取最新户数**
- 但 P25 + P21 v2 联合 = **事后验证**（"如果当时能取到"）
- 实战价值：**复盘 C3 真假**比**实时阻断**更重要
