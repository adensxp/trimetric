# P29 · 股权质押风险阻断（StockPledge · V5.2.5 新增）

> **背景**：V5.2.3 P18 风险股阻断只查 ST/*ST/退市/B 股，**漏掉了"高质押率+股价跌"= 强制平仓踩踏**这种真实风险。V5.2.5 实战中际旭创累计质押率 < 1% 无风险，但很多高 PE 股票都有这个问题。
>
> **数据源**：恒生 `StockPledge`（出质人 / 质权人 / 质押比例 / 质押原因 / 起始/截止日 / 股价）

---

## 29.1 股权质押风险

- **股权质押** = 股东把股票作为担保品向券商/银行借款
- **平仓线** = 借款额 / 质押股数 × 0.6-0.7（预警/平仓线）
- 当股价跌到平仓线 → **强制平仓** = **大单砸盘 + 跌停板风险**

**典型案例**：
- 2024 年多家 A 股公司因质押爆仓引发暴跌
- 15%+ 质押率 + 股价 30%+ 跌幅 = 高风险

---

## 29.2 质押率阈值

| 累计质押率 | 风险等级 | P29 判定 |
|-----------|---------|---------|
| **< 5%** | **极低** | ✓ 安全 |
| 5% ~ 20% | 低 | 中性 |
| 20% ~ 40% | 中 | ⚠ 关注 |
| 40% ~ 60% | 高 | 🔴 风险 |
| **> 60%** | **极高** | 🔴🔴 **强制平仓风险** |

**关键阈值**：
- > 40% = **触发 P18 风险股阻断补强**
- > 60% = **直接阻断分析**（除非用户明确接受风险）

---

## 29.3 实战判定流程

### Step 1: 累计质押率
```
sum = Σ 各笔质押股数 / 总股本
IF sum > 60%:
    P29 = "极高风险"
    → 触发 P18 阻断补强
IF sum > 40%:
    P29 = "高风险"
    → 报告标注, 加仓信号降两档
IF sum > 20%:
    P29 = "中等风险"
    → 报告标注
ELSE:
    P29 = "低风险"
    → 正常流程
```

### Step 2: 平仓风险预估
```
平仓价 = 质押均价 × 0.65（标准预警平仓线）
当前价 < 平仓价 ?
    是 → 报告标注"已进入平仓区"
    否 → 计算距平仓线幅度
```

### Step 3: 质押原因分类
```
质押原因 = 偿还债务 / 债权类投资 / 股权投资 / 个人融资
- 偿还债务/个人融资 = 弱势方（被动质押）
- 债权类投资/股权投资 = 强势方（主动融资）
```

## 29.5 P29 与 P18 的关系

```
P18 风险股阻断（V5.2.3）：
  - ST / *ST / 退市 / B 股 → 直接阻断
  - 大股东减持 > 1% / 重组停牌 → 短期 5 日内减仓 S1 警戒

P29 质押风险（V5.2.5 新增）← 补强 P18：
  - 累计质押率 > 60% → 触发 P18 阻断
  - 累计质押率 > 40% → 加仓信号降两档
  - 当前价 < 平仓价 → 报告必须标注
```

**P29 是 P18 的"金融工程"补强**——抓"看似正常但财务结构脆弱"的股票。

---

## 29.6 P29 实战应用场景

### 场景 1: 科技股 / 高 PE 股
- 很多公司大股东高质押
- 股价跌 30% + 质押率 > 40% = **强制平仓风险**
- P29 必须先查，**不查不分析**

### 场景 2: 蓝筹 / 银行股
- 银行股大股东通常是国资/财政部
- 质押率极低（< 5%）
- P29 通常无影响

### 场景 3: 重组 / 借壳预期股
- 重组方常通过股权质押融资
- 质押率可能 > 30%
- P29 关注 + 公告事件联动

## 29.7 P29 与 P21 v2 联动

P21 v2 C3 三步验证增加"Step 4 质押风险"：
```
IF C3 触发 AND 累计质押率 > 40%:
    P29 = "高风险"
    → 严格清仓（即使 P23/P24/P25 都判定假破位）
    → 理由：质押爆仓风险高于"假破位"概率
```

**中际旭创 8-10 C3 实战**：
- 累计质押率 < 1% → P29 无影响
- P21 v2 三步验证继续走 P23/P24/P25 流程
- **P29 在这里没推翻 P21 v2 的"假破位"判定**

---

## 29.8 P29 输出规范

报告必须包含：
```
【P29 质押风险】
  累计质押率: X% (分子/分母: 614 万股 / 111111 万股)
  风险等级: 极低 / 低 / 中 / 高 / 极高
  距平仓线: X% (当前价 vs 估算平仓价)
  主要质权人: 中信证券 / 国泰海通 / 广发证券 / ...
  风险评估: 正常 / 关注 / 阻断
```
