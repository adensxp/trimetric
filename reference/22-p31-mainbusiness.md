# P31 · 主营构成业务验证（MainOperIncData · V5.2.5 新增）

> **背景**：V5.2.4 实战比亚迪 2025 主营显示**整体毛利率 -8.71% 同比下降**（汽车价格战影响），这是 V5.2.4 漏掉的关键基本面信号。V5.2.5 P31 强制每次分析都查主营构成。
>
> **数据源**：恒生 `MainOperIncData`（产品/区域/客户分类的主营收入/毛利率/同比）

---

## 31.1 主营构成基础

按"实战最有价值"的分类方式：

| 分类方式 | 实战价值 |
|---------|---------|
| **按产品** | ⭐⭐⭐⭐⭐ 最常用（业务真实性）|
| 按区域 | ⭐⭐⭐⭐（地域风险）|
| 按客户 | ⭐⭐⭐（集中度风险）|
| 按行业 | ⭐⭐（粗分类）|

## 31.2 关键信号

### 31.2.1 主营毛利率变化

| 主营毛利率同比变化 | 解读 | 信号 |
|------------------|------|------|
| **> +5%** | **毛利率大幅提升** | 强信号（议价能力提升）|
| +1% ~ +5% | 提升 | 标准 |
| -1% ~ +1% | 持平 | 中性 |
| -5% ~ -1% | 下降 | 关注 |
| **< -5%** | **毛利率大幅下降** | **价格战/成本上升**（风险信号）|

### 31.2.2 主营集中度（前 1 大产品占比）

| 前 1 大产品占比 | 解读 | 信号 |
|----------------|------|------|
| **> 80%** | **高度集中** | 业务单一（风险）|
| 60-80% | 较集中 | 标准 |
| 40-60% | 中等 | 平衡 |
| < 40% | 分散 | 业务多元 |

### 31.2.3 主营增长率

| 近 3 年复合增长率 | 解读 | 信号 |
|------------------|------|------|
| **> 30%** | **高速增长** | 强信号 |
| 10-30% | 稳定增长 | 标准 |
| 0-10% | 缓慢增长 | 关注 |
| **< 0%** | **下滑** | 风险信号 |

---

## 31.3 P31 实战判定

### Step 1: 整体毛利率变化
```
IF 主营毛利率同比变化 < -5%:
    P31 = "毛利率大幅下降"
    → 报告标注"价格战/成本风险"
    → 加仓信号降一档
```

### Step 2: 主营集中度
```
IF 前 1 大产品占比 > 80%:
    P31 = "业务单一"
    → 报告标注"业务集中度风险"
    → 不影响加仓信号（公司可能是行业龙头）
```

### Step 3: 主营增长率
```
IF 近 3 年复合增长率 < 0%:
    P31 = "主营下滑"
    → 加仓信号降两档
```

## 31.4 实战案例

### 比亚迪 002594（2025 年报）

| 主营分类 | 营收（亿）| 占比 | 毛利率 | 同比 |
|---------|---------|------|--------|------|
| **汽车/汽车相关产品** | - | 70%+ | 20.49% | **-8.16%** ⚠ |
| 手机部件/组装 | - | 20%+ | 6.29% | **-24.58%** ⚠⚠ |
| 其他 | - | 10%- | 17.59% | +26.41% ✓ |
| **合计** | **8039.65** | 100% | 17.74% | **-8.71%** ⚠ |

**关键发现**：
- **整体毛利率 -8.71% 同比下降** → **价格战影响**（行业 2025 年价格战）
- 主营业绩**双下滑**（汽车 + 手机）
- **"其他"业务毛利率 +26%** 但占比小

**P31 判定**：
- P31 = "毛利率大幅下降 + 主营下滑" ⚠
- 加仓信号降一档
- 实战建议：**比亚迪需密切关注价格战对利润的持续冲击**

### 中际旭创 300308（2025 中报已隐含）

V5.2.4 实战中已通过 `ConsensusExpectation` 看到：
- 2025 全年营收预计 +145%
- 2025 全年净利 +128.17%
- **主营高速增长 +128%** ✓

**P31 判定（中际旭创）**：
- P31 = "主营高速增长" ✓
- **V5.2.5 还需要补取中际旭创的 MainOperIncData 详细数据**（V5.2.5 实战记录中标注待补）

### 贵州茅台 600519

茅台主营 95%+ 是白酒（高度集中），毛利率长期 90%+。
**P31 判定**：
- P31 = "业务高度集中但毛利率极高"（典型防御股）
- 加仓信号**不调整**（高度集中 + 高毛利 = 商业护城河）

## 31.5 P31 与其他规则的关系

```
P19 PE 分位
↓
P31 主营构成（业务真实性，硬数据）← V5.2.5 新增
↓
P19 双引擎
↓
P14 组合管理
```

**P31 触发时**：
- 主营毛利率 -8.71% 同比 → **P19 双引擎的"PE 低估"很可能是"价格战陷阱"**（PE 看着低但利润在下滑）
- 报告必须联动输出："PE 估值低 + 主营毛利率下滑 = 价格战风险"

报告必须包含：
```
【P31 主营构成】
  主营分类方式: 按产品
  前 3 大产品:
    1. [产品名] 营收 X 亿, 占比 X%, 毛利率 X% (同比 X%)
    2. [产品名] 营收 X 亿, 占比 X%, 毛利率 X% (同比 X%)
    3. [产品名] 营收 X 亿, 占比 X%, 毛利率 X% (同比 X%)
  整体毛利率: X% (同比 X%)
  近 3 年复合增长率: X%
  判定: 高速增长 / 稳定 / 下滑 / 业务单一
  影响: 加仓信号调整 / 风险标注
```
