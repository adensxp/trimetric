### 21.2 P11 · 双轨制高量优先级

> **问题**：长线机构票用 P2（量≥5日均量×1.8），普通品种用"量>前3日 max"——同一只票某天可能两个定义都满足，决策混乱。

#### 21.2.1 统一规则

```
IF 标的是长线机构票（一级/二级，P13 定义）:
    IF 量 ≥ 5日均量 × 1.8:
        → 严格长线高量（用 P2 流程）
    ELIF 量 > 前 3 日 max AND 量 ≥ 5日均量 × 1.5:
        → 普通高量（用普通流程，长线票"从严"标准）
    ELSE:
        → 非高量
ELSE:
    → 标准流程：量 > 前 3 日 max 为高量
```

**核心原则**：**长线机构票"从严"，普通品种"从宽"**。

#### 21.2.2 长线二级票的特殊处理

P13 定义的"长线二级票"（边缘长线）：
- P2 高量阈值放宽到 **5日均量 × 1.5**（不是 1.8）
- 其他规则与一级票相同

#### 21.2.3 实战案例

| 标的 | 5日均量 | 1.8x | 1.5x | 4/29 量 | 4/30 量 | 判定 |
|---|---|---|---|---|---|---|
| 伊利 4/29 | 66 万 | 119 万 | 99 万 | 126 万 | - | **严格长线高量** |
| 伊利 4/30 | 101 万 | 182 万 | 152 万 | - | 214 万 | **严格长线高量** |
| 紫金 8/5 | 282 万 | 508 万 | 423 万 | - | 431 万 | **普通高量**（量未达 1.8x） |

**4/29-4/30 伊利**是真正的"主力进攻"双高量；**8/5 紫金**只是普通高量（未达 1.8x），用普通三天定性流程。
