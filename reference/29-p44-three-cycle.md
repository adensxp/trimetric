# P44 - 三周期操作方案

> **版本**: V5.2.9 新增
> **优先级**: P0
> **驱动案例**: 强烈买入组短期反而亏（V5.2.8 关键失误）

## 一、问题背景

**V5.2.8 严重问题**（30 龙头 × 3 起点 × 3 窗口 × 3 周期 = 270 次决策）：

| 周期 | 强烈买入表现 | 持有表现 | 减仓表现 | 卖出表现 |
|------|------------|---------|---------|---------|
| 短 (1.5 月) | **-5.71%** ❌ | -5.60% | **+3.53%** ⭐ | -0.52% |
| 中 (3 月) | -7.45% | -7.90% | +2.04% | -3.08% |
| 长 (1 年) | -6.89% | -6.03% | +7.80% | +7.64% |

**关键发现**：
- 强烈买入组**3 个周期全部亏损**
- 减仓组**3 个周期都正收益**（最稳健）
- 短期/长期需要不同策略

## 二、规则定义

### 三周期操作方案（V5.2.9.2 最终版）

```python
def apply_p44(decision, cycle):
    """
    根据用户周期调整 V5.2.8/V5.2.9 决策
    cycle: '短' (1-3 月) / '中' (3-12 月) / '长' (1+ 年)
    """
    
    if cycle == '短':
        # 短期：买入改持有；强烈买入/持有改减仓
        m = {
            '🟢🟢🟢🟢🟢 强烈买入': '🟡🟡 减仓',  # 短期强烈买入 -5.71% 仍亏
            '🟢🟢🟢🟢 买入': '🟢🟢🟢 持有',         # 修正：买入→持有
            '🟢🟢🟢 持有': '🟡🟡 减仓',              # 短期持有 -5.60% 仍亏
            '🟡🟡 减仓': '🟡🟡 减仓',                  # 维持
            '🔴 卖出': '🔴 卖出',                      # 维持
        }
    
    elif cycle == '中':
        # 中期：保持 V5.2.8/V5.2.9 决策
        # 原因：V5.2.8 验证 - 中期持有 1 年 +42.26% 表现好
        m = {
            '🟢🟢🟢🟢🟢 强烈买入': '🟢🟢🟢🟢 买入',  # 降一档（短期亏）
            '🟢🟢🟢🟢 买入': '🟢🟢🟢🟢 买入',         # 维持
            '🟢🟢🟢 持有': '🟢🟢🟢 持有',              # 维持
            '🟡🟡 减仓': '🟡🟡 减仓',                  # 维持
            '🔴 卖出': '🔴 卖出',                      # 维持
        }
    
    else:  # 长
        # 长期：买入组表现最佳（+42.26% 1 年）
        m = {
            '🟢🟢🟢🟢🟢 强烈买入': '🟢🟢🟢🟢🟢 强烈买入',  # 维持
            '🟢🟢🟢🟢 买入': '🟢🟢🟢🟢 买入',              # 维持
            '🟢🟢🟢 持有': '🟢🟢🟢🟢 买入',              # 提升一档
            '🟡🟡 减仓': '🟢🟢🟢 持有',                  # 提升一档
            '🔴 卖出': '🟡🟡 减仓',                    # 降一档（不清仓）
        }
    
    return m.get(decision, decision)
```

## 三、为什么短/中/长要分开

### 短期（1-3 月）：市场噪声主导
- 任何买入组短期都接近随机
- 减仓组胜率 87.5% ⭐（最稳健）
- 强烈买入反而短期亏（追高风险）

### 中期（3-12 月）：行业 + 财务主导
- 持有组 1 年 +42.26% ⭐（最稳健）
- 减仓组表现一般
- 强烈买入被降一档

### 长期（1+ 年）：估值 + 龙头主导
- 买入组 1 年 +42.26% ⭐
- 持有组提升到买入
- 减仓组提升到持有
- 卖出组降一档（不清仓）

## 七、注意事项

1. **用户必须明确周期**：不明确时默认"中"
2. **周期可调整**：同一只票可以短期看"减仓"，长期看"持有"
3. **P44 不改变 V5.2.9 决策**：只在 V5.2.9 基础上调整
4. **短周期不等于"频繁交易"**：1-3 月持有期，不是日内交易
