# P36 · 机构调研热度（InstitutionInvestigation · V5.2.6 新增）

> **背景**：V5.2.6 实战比亚迪 6-30~7-9 共 10 天内 **4 笔机构调研**（高盛/中信/长江/美银）= 机构关注度**显著提升**。这是 P28 十大股东之外的**"机构关注面"信号**。
>
> **数据源**：恒生 `InstitutionInvestigation`（调研日期 / 调研方式 / 调研人员 / 调研内容 / 接待人员）

---

## 36.1 机构调研基础

- 机构调研 = 买方/卖方/财经媒体**实地访问上市公司**
- **调研频率高** = 机构关注度高（往往对应潜在加仓/降仓）
- **调研内容**透露公司经营动态

---

## 36.2 P36 关键信号

### 36.2.1 调研频率

| 30 日内调研次数 | 信号 |
|----------------|------|
| **0 次** | 机构不关注 |
| 1-2 次 | 标准 |
| 3-5 次 | 关注度提升 |
| **6+ 次** | **高度关注** |

### 36.2.2 调研机构类型

| 机构类型 | 信号价值 |
|---------|---------|
| **顶级外资**（高盛/摩根/美银/瑞银）| ⭐⭐⭐⭐⭐ |
| 顶级内资（中信/中金/华泰）| ⭐⭐⭐⭐ |
| 海外（其他国家机构）| ⭐⭐⭐ |
| 二线机构 | ⭐⭐ |

### 36.2.3 调研时间窗口

| 距业绩公告 | 信号 |
|-----------|------|
| 业绩公告前 30 日 | 关注业绩 |
| 业绩公告后 30 日 | 关注业绩兑现 |
| 其他 | 关注业务发展 |

---

## 36.3 P36 实战判定

### Step 1: 30 日内调研频率
```
IF 30 日内调研次数 >= 6:
    P36 = "高度关注"
    → 加仓信号提一档
ELIF 30 日内调研次数 >= 3:
    P36 = "关注度提升"
    → 加仓信号不调整（仅报告标注）
ELIF 30 日内调研次数 == 0:
    P36 = "机构不关注"
    → 加仓信号降一档
```

### Step 2: 机构类型
```
IF 顶级外资 + 顶级内资 各 >= 1 笔:
    P36 = "顶级机构关注"
    → 加仓信号提一档
```

### Step 3: 调研内容主题
```
调研内容主题分析:
  - 海外业务 → 关注国际化进展
  - 新产品/新技术 → 关注成长性
  - 价格战/毛利率 → 关注盈利可持续性
  - 股东回报 → 关注分红
```

## 36.4 实战案例

### 比亚迪 002594（2026-06-30 ~ 07-09 共 4 笔调研）

| 调研日 | 机构 | 关注主题 |
|--------|------|---------|
| 2026-07-09 | 美银美林 | 海外销售 / 储能 / 新车型 / 智能化 |
| 2026-07-09 | 长江证券 | 海外业务 / 高端品牌出海 / 闪充 / 半导体 |
| 2026-07-02 | 高盛国际 Tina Hou | 6 月销售 / 巴西 / 英国 / 储能 / 智能化 |
| 2026-07-01 | 中信证券 | 闪充 / 智能化 / 海外 / 储能 / 半导体 |
| 2026-06-30 | 中信证券 | 行业 / 国内销售 / 海外 / 智能化 / 储能 |

**P36 判定**：
- 10 天内 **4 笔调研** = **高度关注**
- **高盛 + 美银 + 中信 + 长江** 4 家顶级机构 = **顶级关注**
- 关注主题集中在：**海外业务 + 闪充技术 + 智能化 + 储能**
- **P36 = "顶级机构高度关注"** ⭐⭐⭐

**P36 与 P33 联合**：
- P33 内部人 2025-09-09 集体增持（37 人）
- P36 机构 2026-06~07 高频调研
- **联合 = 内部看好 + 机构看好 = 极强看多信号**

**P36 与 P31 联合**：
- P31 主营毛利率 -8.71%（**价格战**）
- P36 机构仍在关注
- **联合 = 价格战是行业问题不是公司问题**（调研内容显示公司护城河仍在：闪充/智能化/海外）

## 36.5 P36 与其他规则的关系

```
P28 十大股东（持仓）
↓
P36 机构调研（关注度）← V5.2.6 新增
↓
P19 业绩预告 + P35 业绩快报
↓
P33 内部人交易
```

**P36 实战价值**：
- **领先信号**（机构调研后 1-3 个月可能加仓）
- **覆盖范围广**（P28 十大股东看不到二线机构）
- **内容丰富**（调研内容透露公司经营动态）

**P36 vs P28 互补**：
- P28 = 持仓面（已经加仓的）
- P36 = 关注面（**可能加仓的**）

## 36.6 P36 输出规范

报告必须包含：
```
【P36 机构调研】
  近 30 日调研次数: X 笔
  顶级机构: 高盛 / 中信 / 中金 / 美银 / 长江（X 家）
  主要关注主题:
    - 海外业务
    - 闪充技术
    - 智能化
    - 储能
  调研方式: 实地 / 电话 / 特定对象
  判定: 高度关注 / 标准 / 不关注
  影响: 加仓信号调整
```
