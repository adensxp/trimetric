# P27 · 融资融券杠杆验证（StockSecuritiesMargin · V5.2.5 新增）

> **背景**：V5.2.4 实战中际旭创发现——**融资客在 8-07 大撤退（-14.83 亿），领先股价 3 天**！这是"主力意图"的硬证据，比 P23 DDE 更长期。
>
> **数据源**：恒生 `StockSecuritiesMargin`（融资余额/融资净买入/融券余量/融资融券差额）

---

## 27.1 杠杆信号基础

- **融资余额** = 投资者借入资金买股的未偿还额
- **融资净买入** = 当日融资买入 - 融资偿还
- **融券余额** = 投资者借入股票卖出的未偿还额
- **融资融券差额** = 融资余额 - 融券余额（> 0 多头主导）

---

## 27.2 关键信号判定

### 27.2.1 融资余额变化（中期信号）

| 5 日融资余额变化 | 解读 | 信号 |
|------------------|------|------|
| **< -15%** | **融资客大撤退** | **顶部信号**（领先股价 3-5 日）|
| -15% ~ -5% | 融资客减仓 | 标准 |
| -5% ~ +5% | 持平 | 中性 |
| +5% ~ +15% | 融资客加仓 | 标准 |
| **> +15%** | **融资客大举加仓** | **底部信号**（领先股价 3-5 日）|

### 27.2.2 融资净买入（短期信号）

| 当日融资净买入 | 解读 | 信号 |
|---------------|------|------|
| **> +5 亿** | **融资客大举追多** | 短期强势 |
| +1 ~ +5 亿 | 融资客小幅加仓 | 标准 |
| -1 ~ +1 亿 | 持平 | 中性 |
| -5 ~ -1 亿 | 融资客减仓 | 风险 |
| **< -5 亿** | **融资客疯狂撤退** | **顶部确立**（次日大概率下跌）|

---

## 27.3 P27 实战判定流程

### Step 1: 融资余额 5 日变化
```
IF 5 日融资余额变化 < -15%:
    P27 = "融资客大撤退"
    → 报告标注, 加仓信号降一档
    → 准备 C 类清仓信号
```

### Step 2: 当日融资净买入
```
IF 融资净买入 < -5 亿:
    P27 = "融资客大撤退"
    → 与 P23 DDE 联合判定
    → DDE -5 亿 + 融资净买入 -5 亿 = 双确认出货
```

### Step 3: 融资融券差额
```
IF 融资融券差额 > 0 AND 融券余额/融资余额 > 5%:
    多空分歧大
    → 警惕多翻空
```

## 27.4 P27 实战案例（中际旭创 300308 · 7-15 ~ 8-13）

| 日期 | 融资余额（亿）| 5 日变化 | 融资净买入（亿）| P27 判定 |
|------|-------------|----------|----------------|----------|
| 7-15 | 429.6 | - | -0.0042 | 持平 |
| 7-20 | 385.4 | -3.1% | -10.26 | 减仓 |
| 7-27 | 397.7 | -2.5% | -4.60 | 减仓 |
| 8-04 | 321.1 | **-19.3%** | **+10.55** | **大撤退 + 当日追多（对倒？）** |
| 8-05 | 325.4 | -19.0% | +4.32 | 继续追多 |
| 8-07 | 310.5 | -22.1% | **-14.83** | **大撤退（领先信号）**|
| 8-10 | 309.3 | -23.6% | -1.27 | 继续撤退 |
| 8-11 | 310.4 | -23.5% | +1.11 | 微加仓 |
| 8-12 | 303.5 | -24.0% | -6.88 | 再次撤退 |
| 8-13 | 306.1 | -25.2% | +2.57 | 微加仓 |

**关键发现**：
- **7-15~8-13 融资余额累计 -28.8%**（429.6 亿 → 306.1 亿，**撤退 123.5 亿**）
- **8-07 撤退 -14.83 亿 = 领先 8-10 暴跌 3 天**
- **8-04 余额已经下降 -19.3% 时主力仍拉 +13.24% = 拉高出货 + 融资客接盘后被套**

**实战意义**：
- 8-10 暴跌时融资余额已下降 -23.6% → **不是新资金撤退，是套牢盘止损**
- P27 单独看：融资客撤退**早于**股价下跌 = **典型顶部信号**
- P27 + P23 联合：8-07 融资 -14.83 亿 + 8-10 DDE -7.22 亿 = **双确认出货**

### V5.2.5 重新判定

| 日期 | V5.2.4 判定 | V5.2.5 P27 联合判定 |
|------|------------|---------------------|
| 8-04 | 真高量·强 | 拉高出货嫌疑（融资客接盘后被套）|
| 8-07 | - | **顶部信号**（融资客 -14.83 亿）|
| 8-10 | 假破位 | **真破位嫌疑 + 但被主力回补**（综合判定仍假破位）|

**P27 实战价值**：
- **领先信号**（比 P23 早 3 天）
- **真实意图**（融资客 = 用真金白银表态）
- 与 P23/P24/P25 联合 = 12 维数据综合判定
