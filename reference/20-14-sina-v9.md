## 20.14 V5.2.1 V2.2 V9 第三源（新浪）接入

> **背景**：V2.1 已实现腾讯 + 恒生两源 V9 验证，但生产环境最好有 ≥3 个独立数据源。
> 新浪财经 K 线在沙箱环境可访问，且与腾讯/恒生数据高度一致，**可作为第三源**。

### 20.14.1 关键发现：新浪数据默认不复权

| 数据源 | 复权方式 | API 字段 |
|---|---|---|
| 腾讯 K 线 | 前复权 | `qfq` 字段（URL `c=`）|
| 恒生 K 线 | 由 `restorationStatus` 决定 | 默认前复权 |
| **新浪 K 线** | **不复权** | **API 无复权参数** |

**实战验证（工行 601398）**：
- 5/13 除权前 5 天，腾讯 7.081 vs 新浪 7.250，差 0.169 = 分红金额
- 5/13 除权后，腾讯 7.141 vs 新浪 7.310，差 0.169 = 仍是分红金额

**结论**：新浪 API 始终返回不复权数据，需手动用分红数据做前复权。

### 20.14.2 `adjust_sina_to_qfq()` 函数设计


**关键 bug 修复**：
- 紫金 8/21 是未来除权日，**但新浪 100 天数据范围在 8/21 之前**
- 错误算法：对 8/21 之前所有 K 线减 0.42（8/21 分红）→ 100% 不一致
- 正确算法：8/21 未发生，不应调整 → 100% 一致 ✓

### 20.14.5 完整工作流（含第三源）

```python
from p9_engine import validate_then_query_full
from multi_source_validator import MultiSourceValidator
from hengsheng_connector import HengshengConnector
from connector__hengsheng__call_api import call_api

# 1. 拉腾讯 K 线（HTTP）
msv = MultiSourceValidator()
tencent = msv.fetch_tencent_klines("601398", count=100)

# 2. 拉新浪 K 线（HTTP，自动前复权）
sina_raw = msv.fetch_sina_klines("601398", datalen=100)

# 3. 拉恒生 K 线（connector 工具）
hengsheng_raw = call_api(
    api_id="StockMultiPeriodQuote",
    params={"stockObject": ["601398.SH"], "beginDate": "2026-08-01",
            "endDate": "2026-08-14", "restorationStatus": "1", "statisticsPeriod": "6"}
)

# 4. 拉分红（V6 + 新浪复权）
divs = HengshengConnector().parse_dividends(
    call_api(api_id="BonusStock", params={"stockObject": ["601398.SH"], 
                                           "beginDate": "2026-01-01", "endDate": "2026-08-14"})
)

# 5. 一键分析（V9 自动用 3 源 + 新浪自动前复权）
result = validate_then_query_full(
    code="601398.SH",
    dividends=divs, hengsheng_raw=hengsheng_raw,
    value_raw=..., announcements=...
)
print(result['card'])
```

### 20.14.6 V9 第三源生产建议

| 场景 | 推荐源数 | 实际可用源 |
|---|---|---|
| 沙箱 | 2-3 | 腾讯 + 恒生 + 新浪 |
| 生产（无沙箱限制）| ≥ 3 | 腾讯 + 恒生 + 新浪 + 东方财富 + Tushare |
| 极致安全 | 4-5 | + 网易财经 + 雪球 |

**核心原则**：独立数据源越多，V9 越能发现数据造假或接口异常。
