# P32 · 并购重组事件驱动（MergerRestructEvent · V5.2.5 新增）

> **背景**：V5.2.4 实战中际旭创漏掉了**8-14 当天公告 17.47 亿元收购中石科技 10.47% 股权**——这是 V5.2.4 实战报告里没考虑到的事件。V5.2.5 P32 强制每次分析都查 6 个月内并购重组事件。
>
> **数据源**：恒生 `MergerRestructEvent`（首次披露日 / 实施完成日 / 标的 / 交易额 / 重组进度）

---

## 32.1 并购重组基础

- **协议收购** = 现金或股份协议受让
- **增资** = 通过增资取得股权
- **资产重组** = 重大资产置换/出售/购买
- **构成重大重组** = 触及《上市公司重大资产重组管理办法》标准

---

## 32.2 实战信号

### 32.2.1 交易金额阈值

| 单笔交易金额 | 信号 |
|-------------|------|
| **> 10 亿元** | **重大事件**（必须报告）|
| 1-10 亿元 | 重要事件（报告标注）|
| < 1 亿元 | 常规投资（可不报）|

### 32.2.2 重组进度

| 进度 | 信号价值 |
|------|---------|
| **实施完成** | 已落地，影响已体现 |
| 决案 | 股东大会通过，临近落地 |
| 预案 | 早期，影响待定 |
| 取消 | 重大利空（撤回）|

### 32.2.3 事件类型

| 类型 | 实战影响 |
|------|---------|
| **重大资产购买** | 战略扩张（利好）|
| **重大资产出售** | 战略收缩（需分析原因）|
| **协议收购股权** | 财务投资（中性）|
| **增资取得控制权** | 重大并购（强利好）|

---

## 32.3 P32 实战判定

### Step 1: 6 个月内重大事件
```
IF 6 个月内 有 > 1 亿元 的并购重组:
    P32 = "事件驱动中"
    → 报告必须标注
```

### Step 2: 事件影响判定
```
IF 重大资产购买 AND 进度 = 实施完成:
    P32 = "战略扩张已落地"
    → 加仓信号提一档
IF 重大资产出售 AND 进度 = 实施完成:
    P32 = "战略收缩已落地"
    → 加仓信号降一档
IF 重组进度 = 取消:
    P32 = "事件撤回"
    → 加仓信号降两档
```

### Step 3: 估值影响
```
IF 收购价 / 当前股价 > 1.1:
    P32 = "溢价收购"
    → 强烈信号（公司愿溢价买入）
IF 收购价 / 当前股价 < 0.9:
    P32 = "折价收购"
    → 警示信号（可能高买低卖）
```

## 32.4 实战案例

### 中际旭创 300308（2024-2026 重大事件）

| 首次披露 | 事件 | 金额 | 进度 | P32 判定 |
|---------|------|------|------|---------|
| **2026-08-14** | **17.47 亿收购中石科技 10.47% 股权** | 17.47 亿 | 预案 | **重大事件** ⭐ |
| 2026-08-12 | 成都智禾认购乾融晟润基金 2745 万 | 0.27 亿 | 预案 | 基金投资 |
| 2025-11-22 | **淡马锡+ADIA 5.17 亿美元增资 TeraHop 67.7%** | 35.7 亿 | 决案 | **强利好**（国资+主权基金入股）⭐⭐ |
| 2025-09-26 | 国泰海通产业基金 3.54 亿 | 3.54 亿 | 实施完成 | 战略合作 |
| 2024-12-30 | 苏州旭创出售集益威半导体 3.36% | 1.03 亿 | 预案 | 资产出售 |

**关键发现**：
- **8-14 公告 17.47 亿收购中石科技** = **V5.2.4 实战漏掉的关键事件**
- 8-14 当天股价涨 +2.38% 跟这个公告相关
- **V5.2.4 报告里"加仓信号未触发"的判断错了——应该提级**
- **2025-11-22 淡马锡+ADIA 入股** = **强主权基金信号**（V5.2.4 没看到）

**V5.2.5 重新判定**：
- 8-14 后应该**重新评估加仓信号**（中际旭创已从纯 AI 算力光模块扩展到散热/热管理）
- P32 实战价值：**收购/被收购是估值重估的硬催化剂**

## 32.5 P32 与其他规则的关系

```
P19 PE 分位
↓
P32 并购重组事件（事件驱动催化剂）← V5.2.5 新增
↓
P31 主营构成（业务验证）
↓
P17 公告事件标注
```

**P32 触发时**：
- 重大资产购买落地 → P31 主营构成**需要重算**（业务结构变了）
- 重大资产出售落地 → P31 主营构成**需剔除该业务**
- 收购方溢价收购 → **P19 PE 估值需重估**（包含被收购方盈利）

## 32.6 P32 实战应用

### 32.6.1 收购方
- 战略并购 = 估值重估窗口
- 关注**协同效应**（业务互补）
- 加仓信号**短期提一档**（事件驱动）

### 32.6.2 被收购方
- 收购溢价 = **短期股价催化**
- 但**注意流动性**（收购后退市风险）
- 实战建议：**溢价 30%+ 卖出**（套利机会）

### 32.6.3 重组失败
- 预案/决案 → 取消 = **重大利空**
- 加仓信号降两档
- **C 类清仓信号可能触发**

## 32.7 P32 输出规范

报告必须包含：
```
【P32 并购重组事件】
  6 个月内事件数: X 笔
  重大事件 (> 1 亿):
    1. [日期] [事件描述] 金额 X 亿, 进度 X
    2. [日期] [事件描述] 金额 X 亿, 进度 X
  战略合作:
    1. [日期] [事件描述] 金额 X 亿
  整体判定: 事件驱动中 / 战略扩张 / 战略收缩 / 重组失败
  估值影响: 溢价收购 / 折价收购 / 中性
  加仓信号调整: 提一档 / 降一档 / 不调整
```
