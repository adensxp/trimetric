## 28.2 P28 关键信号

### 28.2.1 北上资金变化

```
IF 上一季度香港中央结算 持股比例变化 > +0.5%:
    P28 = "北上大幅加仓"
    加仓信号提一档
    
IF 上一季度香港中央结算 持股比例变化 < -0.5%:
    P28 = "北上大幅减仓"
    加仓信号降一档
```

**中际旭创 2026-Q1 实战**：
- 香港中央结算 持股 6.97%（**+1.41% 季度变化**）
- 从 ~5.56% 升到 6.97% = **+25% 相对变化**
- **P28 = "北上大幅加仓"** ✓

### 28.2.2 大股东变化

```
IF 控股股东减持 > 0.5%:
    P28 = "大股东减持"
    风险信号 → 加仓信号降两档
    
IF 控股股东增持 > 0.5%:
    P28 = "大股东增持"
    强信号 → 加仓信号提两档
```

**中际旭创 2026-Q1 实战**：
- 山东中际投资控股 -0.06%（轻微减仓）
- 王伟修 6.28%（未变）
- **P28 = "大股东轻微减仓"** ⚠（轻微，不构成强信号）

### 28.2.3 多股东综合判定

```
IF 3 个以上十大股东 同时增持:
    P28 = "主力集体加仓"
    极强信号
    
IF 3 个以上十大股东 同时减持:
    P28 = "主力集体撤退"
    极强风险信号
```

## 28.3 P28 实战应用

### 28.3.1 与 P25 户数联合

| P25 户数 | P28 十大股东 | 联合判定 |
|---------|--------------|---------|
| 下降 | 加仓 | **主力回补**（假破位概率高）|
| 下降 | 减持 | **主力悄悄撤退**（真破位）|
| 上升 | 加仓 | 主力建仓中，散户跟买 |
| 上升 | 减持 | **主力派发**（最危险）|

**中际旭创 2026-Q1 联合判定**：
- P25 户数 -15.8% 下降
- P28 北上 +1.41% 加仓，大股东 -0.06% 轻微减仓
- **联合判定：主力回补（北上主导）= 假破位剧本继续成立** ✓

### 28.3.2 与 P19 双引擎联合

```
IF P28 北上加仓 + PE 估值高位:
    估值高但外资看好 = 强持有信号
    → 不触发减仓
    
IF P28 北上减仓 + PE 估值低位:
    估值低但外资撤退 = 弱信号
    → 加仓信号降一档
```

## 28.4 P28 实战案例（中际旭创 300308 · 2026-Q1 十大股东）

| 排名 | 股东名称 | 性质 | 持股比例 | 季度变化 | P28 判定 |
|------|---------|------|---------|----------|----------|
| 1 | 山东中际投资控股 | 控股股东 | 10.93% | -0.06% | 轻微减仓 |
| 2 | **香港中央结算** | **北上资金** | **6.97%** | **+1.41%** | **大幅加仓** ⭐ |

**实战意义**：

- **P28 是 P23/P25 之外第三个"主力行为"维度**
