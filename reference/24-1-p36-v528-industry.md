## 🎯 规则概述

P36 行业判断是 V5.2.8 新增的核心规则，**在决策前对行业进行周期判断，避免行业下行股（如房地产/家居/零售）**。

**核心价值**：V5.2.7 实战中 1 年里 5 票"行业下行股"导致 5.9% 平均损失（赛力斯 -58% / 万科 -52% / 欧派 -37% / 永辉 -34% / 分众 -30%），P36 行业判断将这些损失前置避免。

## 🛠️ 行业判断方法

### 方法 1：政策面

| 信号 | 评分 | 说明 |
|------|------|------|
| 国家产业政策支持 | +2 | 政府工作报告点名支持 |
| 政策中性 | 0 | 无明显支持/打压 |
| 政策打压 | -2 | 反垄断/限制/调控 |

### 方法 2：需求面

| 信号 | 评分 | 说明 |
|------|------|------|
| 行业销量同比 +20% 以上 | +2 | 强需求 |
| 行业销量同比 ±20% | 0 | 平稳 |
| 行业销量同比 -20% 以下 | -2 | 弱需求 |

### 方法 3：估值面

| 信号 | 评分 | 说明 |
|------|------|------|
| 行业 PE 历史分位 < 30% | +1 | 低估 |
| 行业 PE 历史分位 30-70% | 0 | 合理 |
| 行业 PE 历史分位 > 70% | -1 | 高估 |

### 方法 4：资金面

| 信号 | 评分 | 说明 |
|------|------|------|
| 北向资金连续 3 月净流入 | +1 | 看好 |
| 北向资金正常 | 0 | 中性 |
| 北向资金连续 3 月净流出 | -1 | 看空 |

### 方法 5：业绩面

| 信号 | 评分 | 说明 |
|------|------|------|
| 行业整体业绩同比 +20% | +2 | 高速增长 |
| 行业整体业绩同比 ±20% | 0 | 平稳 |
| 行业整体业绩同比 -20% | -2 | 下滑 |

### 综合判断

| 总分 | 周期类型 | V5.2.8 处理 |
|------|---------|------------|
| ≥ +5 | 强周期上行 | 🟢🟢🟢🟢🟢 强烈买入 |
| 0 ~ +4 | 弱周期上行 | 🟢🟢🟢🟢 买入/持有 |
| -4 ~ -1 | 强周期下行 | 🟡🟡 减仓 |
| ≤ -5 | 弱周期下行 | 🔴🔴 卖出 |

## 🎯 V5.2.8 实施要点

### 1. 决策前必须做行业判断

- **任何决策前**先查 P36 行业判断
- 强周期下行/弱周期下行行业 → 强制减仓/卖出
- 强周期上行/弱周期上行行业 → 优先强烈买入/买入

### 2. 行业判断优先级

```
P18 风险阻断
↓
P40 行业下行股卖出（V5.2.8 强制触发）
↓
P37 行情判断（前置）
↓
P36 行业判断（前置）← V5.2.8 新增
↓
其他规则
```

### 3. 实战首例查询

每只票实战前必查：
1. 票所属行业（申万一级）
2. 行业当前周期类型（强周期上行/弱周期上行/强周期下行/弱周期下行）
3. 对应实战首例是否命中
4. 应用 P36-V5.2.8 决策
