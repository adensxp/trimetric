### 21.6 P15 · P6 形态量化阈值

> **问题**：紫金 8/11 我判"无下影抛压"，但"下影多少算无下影"是主观的。

#### 21.6.1 P6 三个出货形态量化

| 形态 | 特征 | 量化阈值 |
|---|---|---|
| **放量滞涨** | 量能放大但涨幅极小 | 1) 量 ≥ 5日均量 × 1.5<br>2) 实体涨幅 < 0.5%<br>3) 上影 / 实体 > 1.5 |
| **缺口出货** | 跳空低开后持续阴跌 | 1) 开盘 vs 前收 < -0.3%（向下跳空）<br>2) 收盘 < 开盘（阴线）<br>3) 量 ≥ 5日均量 × 1.2 |
| **无下影抛压** | 收盘=最低，无承接 | 1) 下影 < 实体 × 5%<br>2) 阴线<br>3) 量 ≥ 5日均量 × 1.2 |

#### 21.6.2 三形态优先级

```
IF 同时满足多个形态:
    → 取最严重者（缺口出货 > 无下影抛压 > 放量滞涨）
```

#### 21.6.3 紫金 8/11 形态验证

| 形态 | 阈值 | 紫金 8/11 实测 | 满足？|
|---|---|---|---|
| 放量滞涨 | 涨幅<0.5% + 上影/实体>1.5 | 涨幅 -6.95% | ✗ |
| 缺口出货 | 跳空< -0.3% + 阴 + 高量 | 跳空 +0.21%（非向下）| ✗ |
| 无下影抛压 | 下影/实体<5% + 阴 + 高量 | 下影 0.07/实体 2.48=2.8% ✓ | ✓ |

**紫金 8/11 = "无下影抛压"形态** ✓

#### 21.6.4 形态与 C 类信号的对应

| 形态 | 触发的 C 类信号 | 操作 |
|---|---|---|
| 放量滞涨 | C1（实体低 × 0.97）/ C5（连涨放量收阴）| T+0 减机动仓 50% |
| 缺口出货 | C1（实体低破位）/ C4（下跌趋势反弹）| T+0 减机动仓 50% |
| 无下影抛压 | C1 / C7（无高量大跌）| T+0 减机动仓 50% |
