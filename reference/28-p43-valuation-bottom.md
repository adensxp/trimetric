# P43 - 估值底部信号

> **版本**: V5.2.9 新增
> **优先级**: P2
> **驱动案例**: 周期股 + 估值底 = 强触底

## 一、问题背景

**V5.2.8 缺失**：
- 没用 PE / PB / 股息率判断估值底
- 估值低 = 安全边际 = 反弹空间
- 是周期股主升浪的"燃料"

**实战价值**：
- 估值底 + 行业下行 = 触底信号
- 估值底 + 高弹性 = 强反弹
- 估值底 + 龙头 = 强触底

## 二、规则定义

### 估值底加分

```python
# PE 估算（用 np_yoy 和历史 EPS 推算）
# 数据库无直接 PE 字段，但可用以下近似：

# 净利润同比 + 高 PE：表明估值不便宜
# 净利润同比 - 低 PE：表明估值便宜
# PE<12 + 振幅>25% = 估值底 + 高弹性

IF PE < 10 AND 股息率 > 3%:
    → 强估值底信号（+2）
ELIF PE < 12 AND 60日振幅 > 25%:
    → 估值底 + 弹性（+1.5）
ELIF PE < 12:
    → 估值底（+0.5）
ELIF PE < 15:
    → 估值合理（无加分）
ELSE:
    → 估值偏贵（-0.5）
```

### 应用场景

P43 在以下规则中应用：
- **P40v2 行业下行分级**：估值底 + 龙头 → 强触底
- **总评分系统**：P43 加分影响最终决策组

## 三、估值底分级

| 估值底强度 | 条件 | 加分 |
|----------|------|------|
| **极强底** | PE<10 + 股息率>4% | +2 |
| **强底** | PE<12 + 振幅>25% | +1.5 |
| **弱底** | PE<12 + 振幅<25% | +0.5 |
| **合理** | 12<PE<15 | 0 |
| **偏贵** | PE>15 | -0.5 |

## 五、PE 估算方法

由于数据库无直接 PE 字段，使用以下方法估算：

```python
def estimate_pe(code, date):
    # 用最近年报 EPS 和当前价格
    cur.execute("""
        SELECT financevalue FROM financial_data
        WHERE stock_code IN (?, ?)
        AND finstatementcode = 'BasicEPS'
        AND report_type = '年报'
        AND report_date <= ?
        ORDER BY report_date DESC LIMIT 1
    """, (code, code[:6], date))
    r = cur.fetchone()
    if not r or not r[0]: return 15  # 默认中等
    
    eps = r[0]
    cur.execute("""SELECT close_price FROM stock_daily
        WHERE stock_code = ? AND trade_date <= ?
        ORDER BY trade_date DESC LIMIT 1""", (code, date))
    price = cur.fetchone()[0]
    
    if eps > 0:
        pe = price / eps
        return pe
    return 50  # 负 PE = 偏贵
```

## 六、估值底与行业的关系

| 行业 | 估值底标准 | 反弹幅度 | 周期 |
|------|----------|---------|------|
| 银行 | PE<6 | +50-100% | 1-2 年 |
| 钢铁 | PB<1 | +30-80% | 1-2 年 |
| 有色 | PE<15 + 高弹性 | +50-200% | 1-2 年 |
| 煤炭 | PE<8 + 股息率>4% | +30-100% | 6 月-1 年 |
| 化工 | PE<10 | +20-50% | 1-2 年 |

## 七、注意事项

1. **PE 估算可能不准**：用最新年报 EPS，但价格已变化
2. **PB 适用于资产驱动行业**：银行/钢铁/地产
3. **PE 适用于成长股**：电子/医药/科技
4. **估值底不是单独信号**：必须配合行业 + 龙头

## 八、配套规则

- **P40v2 行业下行分级**：P43 决定是否进入"持有"或"买入"
- **P41 周期股反向**：P43 是 P41 加分项之一
- **P42 龙头识别**：P43 配合 P42 触发"强触底"
- **P44 三周期操作**：长周期 P43 升级决策
