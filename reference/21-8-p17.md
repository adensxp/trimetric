### 21.8 P17 · 公告事件自动标注

> **问题**：完全没考虑除权/分红/回购/重组/业绩预告等公告事件对信号的影响。

#### 21.8.1 公告事件检测清单

| 事件 | 检测方法 | 影响 |
|---|---|---|
| **除权除息** | 价格跳变 + 分红公告匹配 | 21.0.2 算法自动识别 |
| **业绩预告** | 同比 ±30% 公告 | 影响 C 信号有效性 |
| **大股东减持** | 公告披露 | 影响 P6 提前减仓判定 |
| **重大资产重组** | 停牌 + 公告 | 冻结所有信号 |
| **股票回购** | 公告披露 | 反向加分项 |
| **限售解禁** | 公告披露 | 短期供给冲击 |

#### 21.8.2 数据接口

```python
# 调用恒生 connector
announcements = connector__hengsheng__call_api(
    api_id="AShareAnnouncement",
    params={"stockObject": ["601398.SH"], "beginDate": "2026-07-01", "endDate": "2026-08-14"}

```

#### 21.8.3 公告事件的信号调整

| 事件 | 信号调整 |
|---|---|
| 业绩预增 ≥ 30% | 仓位上限 +10% |
| 业绩预减 ≥ 30% | 仓位上限 -10% |
| 股东减持 > 1% | 触发 P6 提前减仓判定 |
| 重组停牌 | 所有信号冻结，标"待复牌" |
| 回购 > 1% | 评级 +1 级（一级→超长线） |
| 限售解禁 5-10% | 短期 5 日内减仓 S1 警戒 |
