# P35 · 业绩快报早期信号（PerformanceExpress · V5.2.6 新增）

> **背景**：V5.2.6 实战中际旭创 2025 业绩快报：**净利 +108.81%（营收 +60.25%）**——这是年报正式披露前 1-2 周的**早期信号**。V5.2.5 P19 业绩预告已用，但业绩快报更早（**比预告再早 1-2 周**）。
>
> **数据源**：恒生 `PerformanceExpress`（基本 EPS / 净利 / 营收 / 同比 / ROE / 报告期）

---

## 35.1 业绩快报 vs 业绩预告 vs 正式年报

| 类型 | 披露时点 | 内容 | 准确性 |
|------|---------|------|--------|
| **业绩快报** | **报告期末 15-30 日** | 营收/净利/EPS/ROE 关键指标 | **估算值**（快速披露）|
| **业绩预告** | 报告期末 30-45 日 | 净利同比 / 区间 | **范围值**（不准确）|
| 正式年报 | 报告期末 60-90 日 | 完整三表 | **精确值**（最准）|

**关键洞察**：
- **业绩快报最早** = 最强领先信号
- 业绩快报早于预告 = 1-2 周领先
- **不准确但够用** = 趋势 + 数量级

## 35.2 P35 关键信号

### 35.2.1 业绩快报同比变化

| 净利同比 | 信号 |
|---------|------|
| **> +50%** | **极强增长** |
| +20% ~ +50% | 强增长 |
| 0% ~ +20% | 稳定 |
| -20% ~ 0% | 下降 |
| **< -20%** | **重大利空** |

### 35.2.2 营收同比 vs 净利同比

| 组合 | 解读 |
|------|------|
| **营收 + 净利都高增长** | 健康成长 |
| 营收高增长 + 净利低增长 | 毛利率下滑（**价格战**）|
| 营收低增长 + 净利高增长 | 毛利率提升（议价能力增强）|
| 都下滑 | 业绩恶化 |

### 35.2.3 ROE 同比

| ROE 同比变化 | 信号 |
|--------------|------|
| **+5pp** | **ROE 大幅提升**（资本效率提高）|
| +1pp ~ +5pp | 提升 |
| -1pp ~ +1pp | 持平 |
| **< -5pp** | **ROE 大幅下降**（资本效率恶化）|

---

## 35.3 P35 实战判定

### Step 1: 净利同比
```
IF 净利同比 > +50%:
    P35 = "强增长"
    → 加仓信号提一档
ELIF 净利同比 < -20%:
    P35 = "业绩下滑"
    → 加仓信号降两档
```

### Step 2: 营收-净利匹配
```
IF 营收 + 净利均 > +20%:
    P35 = "健康成长"
ELIF 营收 > +20% AND 净利 < +20%:
    P35 = "毛利率下滑"
    → 报告标注
```

### Step 3: ROE 趋势
```
IF ROE 同比 > +5pp:
    P35 = "ROE 提升"
    → 加仓信号提一档
```

## 35.4 实战案例

### 中际旭创 300308（2025 业绩快报）

| 指标 | 2025 | 2024 | 同比 |
|------|------|------|------|
| 营收（万元）| 3,823,998 | 2,386,149 | **+60.25%** |
| 净利（万元）| 1,079,863 | 517,081 | **+108.81%** |
| 基本 EPS（元）| 9.80 | 4.71 | +107.63% |
| 营业利润（万元）| 1,359,692 | 605,079 | +124.74% |
| ROE | 35.99% | 27.02% | **+8.97pp** |

**P35 判定**：
- 营收 +60.25% + 净利 +108.81% = **健康成长**
- ROE +8.97pp = **资本效率大幅提升**（**P20 科技股高 PE 担忧被 ROE 提升对冲**）
- **加仓信号提一档**

**与 P19 业绩预告交叉验证**：
- P19 业绩预告：2025 全年净利 +128.17%（区间）
- P35 业绩快报：+108.81%（估算）→ **P35 更准确**

### 比亚迪 002594

V5.2.6 业绩快报返回前几条是 2012-2019 历史数据，**最新 2025 业绩快报未返回**（可能已转用 PerformanceForecast 覆盖）。**实战限制**：
- 比亚迪 2025 业绩**靠 P19 业绩预告 + 主营构成 P31 验证**
- P31 主营毛利率 -8.71% = **价格战** → 业绩快报应**已体现**
- **实战价值**：P35 与 P19 互补，**P19 覆盖不到时 P35 兜底**

### 贵州茅台 600519

V5.2.6 业绩快报只返回 2007/2011/2021 早期数据，**最新 2025 业绩快报未返回**。**实战限制**：
- 茅台 2025 业绩**靠 P19 业绩预告**
- 茅台业绩稳定，**P35 边际价值有限**

## 35.5 P35 实战价值

**P35 优势**：
- **最早披露**（领先预告 1-2 周，领先年报 4-6 周）
- **核心指标**（营收/净利/EPS/ROE 一应俱全）
- **跨年对比**（自动同比）

**P35 限制**：
- **估算值**（不是精确数）
- **数据不全**（部分公司不发布业绩快报）
- **历史数据为主**（新数据可能未及时入库）

---

## 35.6 P35 与 P19 关系

```
P19 业绩预告 (P17 公告)
  ↓
P35 业绩快报 (V5.2.6 新增)
  ↓
正式年报
```

**实战**：
- P19 触发 → 看 P35 是否一致
- P35 与 P19 不一致 → **以 P35 为准**（快报更近）
- P35 缺数据 → **回退 P19**

---

## 35.7 P35 输出规范

报告必须包含：
```
【P35 业绩快报】
  最新报告期: YYYY-MM-DD
  营收: X 亿 (同比 Y%)
  净利: X 亿 (同比 Y%)
  基本 EPS: X 元 (同比 Y%)
  ROE: X% (同比 Y pp)
  营收-净利匹配: 健康成长 / 毛利率下滑 / 议价能力提升 / 业绩恶化
  判定: 强增长 / 稳定 / 下滑
  影响: 加仓信号调整
```
