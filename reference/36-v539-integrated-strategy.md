# V5.3.9 整合策略（以盈利为最终目的）

## 一、核心组成

V5.3.9 整合 V5.2.5 + V5.3.6 + V5.3.8 的最优元素：
1. **多版本投票机制**（V5.2.5 + V5.3.6 + V5.3.8 各决策一票）
2. **多周期交叉验证**（短/中/长三周期投票）
3. **P45 操作链**（V5.3.7 + V5.3.8 T+3 止损）
4. **行业分组仓位**（高/中/低命中 1.2/1.0/0.5 倍）
5. **分批建仓**（30% → 30% → 20%）
6. **业绩连降加权**（P49 + 3 年 ROE）
