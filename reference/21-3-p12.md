### 21.3 P12 · 缩量横盘临界值处理

> **问题**：5日均量在 20日均量 × 70% 边界（±10%）时，是"缩量横盘"还是"正常下跌"？

#### 21.3.1 临界值定义

| 比值 | 状态 | 处理 |
|---|---|---|
| < 0.9 × 阈值 | **确认缩量** | 直接判定缩量横盘 |
| 0.9 × 阈值 ~ 1.1 × 阈值 | **临界** | **再观察 1-2 个交易日** |
| > 1.1 × 阈值 | **正常** | 不算缩量横盘 |

#### 21.3.2 临界状态的双轨判定

```
IF 当前 5日均量在阈值 ±10% 内:
    标记 "CRITICAL_VOLUME"
    观察下 1-2 个交易日:
        IF 持续 3 日 5日均量 ≤ 阈值 1.1 倍:
            → 确认缩量横盘
        IF 出现放量（量 ≥ 5日均量 × 1.5）:
            → 取消缩量横盘判定，回到正常下跌流程
```

#### 21.3.3 实战案例

伊利股份 8/14：
- 5日均量 44.6 万
- 20日均量 × 70% = 45.5 万
- 比值 = 44.6 / 45.5 = 0.98 → **临界（0.9-1.1 范围内）**
- 处理：标 CRITICAL_VOLUME，等 8/15 验证
  - 8/15 继续缩量 → 确认 → 可走 L4 路径
  - 8/15 放量 → 取消 → 走普通下跌流程
