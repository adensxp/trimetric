# V5.3.11 简化架构：短行情 + 长线

## 核心改动

V5.3.11 在 V5.3.10 基础上做**架构简化**——取消"短/中/长"三周期，改为"短行情 + 长线"两套规则。

### 之前 V5.3.10 三周期问题

```
短周期（1 月内）   P45 短线链
中周期（1 月-1 年） P45 中线链
长周期（1+ 年）    P45 长线链
```

**问题**：
- 一笔操作到底是"中线"还是"短线"？建仓时不知道
- 中线 1 个月后突然发现"应该是短线"——规则不一致
- 三套规则容易混

### V5.3.11 两套规则

```
┌─────────────────────────────────────────┐
│ 短行情（3 年以下）                       │
│   - 统一一套 P45                        │
│   - 建仓：启动期 + 高量 + 底分型        │
│   - 持有：20-30 天（信号化清仓）        │
├─────────────────────────────────────────┤
│ 长线（3+ 年）                            │
│   - 选股：PE<15 / ROE>10% / 股息率>3%  │
│   - 持有：1-3 年                         │
│   - 信号失效不减仓                       │
└─────────────────────────────────────────┘
```

## 短行情 P45 详细规则

### 建仓信号（3 信号叠加）

| 信号 | 条件 | 权重 |
|------|------|------|
| S1 启动期 | 沪深 300 60 日 > -10% | 1 |
| S2 高量 | 5 日量 / 30 日量 > 1.3 | 1 |
| S3 底分型 | T-2 阳 + T-1 阴 + T 阳且破 T-2 高 | 1 |

**仓位**：
- 3 信号全满足 → 30% 仓位
- 2 信号 → 20% 仓位
- 仅 S1（启动期）→ 10% 仓位
- 0 信号 → 不建仓

### 动态 P45 操作链

| 时点 | 决策 |
|------|------|
| T+0 | 建仓（30/20/10%） |
| T+3 | 跌>8% 减仓30%止损；跌3-8% 观望；涨<3% 持有 |
| T+5 | 跌>5% 减仓30%止损；涨>3%+量能放大 加仓30%；否则持有 |
| T+10 | 跌<0% 减仓15%止损；涨>5%+量能 加仓30%；涨3-5% 减仓15%锁利 |
| T+15 | 跌>5% 清仓止损；涨>5% 减仓15%锁利；涨0-5% 减仓10% |
| T+20 | **信号化**（V5.3.10 是强制清仓） |
| T+30 | **信号化清仓**（替代 T+20 强制） |

### T+20 信号化（新规则）

V5.3.10：T+20 强制清仓
V5.3.11：T+20 信号化决策

| T+20 状态 | 动作 |
|-----------|------|
| 跌 > 10% | 全部清仓 |
| 跌 5-10% + 跌破 10 日线 | 清仓止损 |
| 跌 0-5% | 减仓 50% |
| 涨 > 5% + 站上 10 日线 + 量能不萎缩 | 持有观望（到 T+30） |
| 其他 | 减仓 30% |

### T+30 信号化清仓

| T+30 状态 | 动作 |
|-----------|------|
| 跌 > 10% | 清仓止损 |
| 跌 < 0% 或跌破 10 日线 | 清仓剩余 |
| 涨 0-5% | 减仓 50% |
| 涨 > 5% + 站上 10 日线 | 减仓 70%（保留 30%）|

## 总结

V5.3.11 简化架构解决了 V5.3.10 的两个问题：
1. **短/中/长混淆** → 简化为短+长两段
2. **T+20 强制清仓** → 改为 T+20/T+30 信号化

虽然 5 年绝对收益略低于 V5.3.10，但**心理清晰、规则简单、错失大波段少**——更适合实战。
