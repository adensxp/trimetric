### 21.9 P18 · 风险股自动阻断

> **问题**：之前手动检查"股票名是否含 ST/退市/B 股"，容易漏。

#### 21.9.1 自动化检测函数

```python
def check_risk_stock(stock_code, stock_name, sector_code):
    """
    输入：股票代码、名称、申万行业
    输出：(是否阻断, 阻断原因, 风险等级)
    """
    # *ST 退市风险
    if "*ST" in stock_name or "ST" in stock_name.split():
        return True, "*ST 退市风险", "🔴 最高"
    
    # ST 风险警示
    if stock_name.startswith("ST") or " ST" in stock_name:
        return True, "ST 风险警示", "🟠 高"
    
    # 退市整理期
    if "退" in stock_name or "退市" in stock_name:
        return True, "退市整理期", "🔴 最高"
    
    # B 股
    if stock_code.startswith(("200", "900")):
        return True, "B 股流动性差", "🟡 中"
    
    return False, None, "🟢 正常"
```

#### 21.9.2 阻断后的处理

- **直接阻断** P1-P19 全部判定流程
- **输出**：风险等级 + 阻断原因 + 严禁买入建议
- **不计算**：技术指标、不应用基本面阈值
- **代码实现**：`p9_engine.py` 的 `check_risk_stock()` 函数（已存在）+ 升级为 P18 标准
