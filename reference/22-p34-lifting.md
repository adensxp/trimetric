# P34 · 限售解禁压力评估（RestrictedStockLifting · V5.2.6 新增）

> **背景**：限售解禁 = 大量限售股可流通 = **强卖压力**。V5.2.6 实战验证：中际旭创/比亚迪/茅台 3 只票**近期均无大解禁计划**——但历史上比亚迪 2014-07-01 解禁 88286 万股（56.56%）导致股价长期承压。
>
> **数据源**：恒生 `RestrictedStockLifting`（解禁日期 / 解禁股份数 / 占总股本 / 占流通A股）

---

## 34.1 解禁基础

- **限售股** = 上市前股东/增发取得的股票，**限定期内不能流通**
- **解禁** = 限售期到期，可流通
- **大股东解禁** = **强卖压力**（大股东通常会套现）
- **增发解禁** = **中等压力**（增发对象可能减持）
- **股权激励解禁** = **弱压力**（员工通常继续持有）

---

## 34.2 P34 关键信号

### 34.2.1 解禁规模阈值

| 解禁股份占总股本 | 信号 |
|----------------|------|
| **< 1%** | **可忽略** |
| 1-3% | 小压力 |
| 3-10% | 中等压力 |
| 10-30% | **重大压力** |
| **> 30%** | **巨量解禁**（历史性事件）|

### 34.2.2 解禁类型

| 解禁类型 | 信号 |
|---------|------|
| **发行前股份** | **极强压力**（原始股东必套现）|
| **增发 A 股** | 中等压力 |
| **股权激励** | 弱压力（员工绑定）|
| **股权分置** | 一次性事件，已过 |

---

## 34.3 P34 实战判定

### Step 1: 未来 6 个月解禁计划
```
IF 未来 6 个月内 有 > 5% 的解禁:
    P34 = "解禁压力中"
    → 报告标注
    → 解禁日前 30 日 加仓信号降一档
```

### Step 2: 解禁日附近判定
```
IF 解禁日 < 30 日:
    P34 = "解禁临近"
    → 加仓信号降两档
    → 解禁日及后续 5 日 减仓/观望
```

### Step 3: 历史解禁参考
```
IF 历史上有 > 30% 的解禁:
    P34 = "曾经历巨量解禁"
    → 关注历史解禁后股价表现
```

## 34.5 P34 实战综合

**3 只票全部无解禁压力** = P34 实战信号**对当前决策无影响**

但 P34 实战价值：
- **未来跟踪**：定期查 6 个月内是否有解禁
- **历史警示**：比亚迪 2014 / 中际旭创 2020 都经历过巨量解禁
- **决策辅助**：解禁日及后续 5 日应**减仓/观望**

---

## 34.6 P34 与其他规则的关系

```
P17 公告事件标注
↓
P34 限售解禁（事件型压力）← V5.2.6 新增
↓
P32 并购重组（事件型催化）
```

**P34 vs P32 互补**：
- P32 = **正面事件**（并购/重组/收购）
- P34 = **负面事件**（解禁/卖压）
- 联合使用 = **事件面完整画像**

---

## 34.7 P34 输出规范

报告必须包含：
```
【P34 解禁压力】
  未来 6 个月解禁:
    [日期] 解禁 X 万股 (Y% 总股本) / [类型] - 距今 Z 日
  历史重要解禁 (> 10%):
    [日期] 解禁 X 万股 (Y% 总股本) / [类型] - 已过
  当前判定: 无压力 / 轻度压力 / 中等压力 / 重大压力
  距下次解禁: X 日
  影响: 加仓信号调整 / 减仓时机
```
