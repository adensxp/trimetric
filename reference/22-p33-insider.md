# P33 · 内部人交易信号（KeyHolderTrande · V5.2.6 新增）

> **背景**：V5.2.5 实战比亚迪发现——**2025-09-09 内部人集体增持**（32 名核心人员 + 5 位高管，均价 105.49 元，**领先当前价 88.90 涨 19%**）。这是**最强内部人信号**，比 P28 十大股东的"持仓面"更直接。
>
> **数据源**：恒生 `KeyHolderTrande`（股东名称 / 股东类型 / 交易方向 / 交易均价 / 关联高管）

---

## 33.1 内部人基础

"内部人" = 公司董事/监事/高级管理人员/核心员工/实际控制人/持股 5% 以上股东。

**关键差异**：
- 内部人**有信息优势**（公司经营情况）
- 内部人**有责任**（买卖需公告，事后追责）
- 内部人**是真金白银表态**（不能用其他资金替代）

---

## 33.2 P33 关键信号

### 33.2.1 集体增持（极强信号）

```
IF 同一公告日 3+ 位内部人 增持:
    P33 = "集体增持"
    → 加仓信号提两档
    → 报告必须重点标注
```

**实战案例（比亚迪 2025-09-09）**：
- **32 名核心人员**（自然人）增持 26.64 万股
- **5 位高管**（杨冬生/周亚琳/李巍/罗忠良/等）增持共 ~20 万股
- **合计 37 位内部人** 集体增持
- **均价 105.49 元**（领先 8-14 当前 88.90 涨 19%）
- **P33 = "集体增持"** ⭐⭐⭐

### 33.2.2 单人增持

```
IF 1 位内部人 增持金额 > 100 万:
    P33 = "单人增持"
    → 加仓信号提一档
```

### 33.2.3 内部人减持（重大利空）

```
IF 内部人减持:
    P33 = "内部人减持"
    → 加仓信号降两档
    → 报告必须标注
    IF 减持金额 > 500 万:
        P33 = "内部人大额减持"
        → 触发 P18 阻断补强
```

### 33.2.4 内部人买卖时间窗口

- 内部人**增持窗口** = 业绩公告前 30 日 + 业绩公告后 10 日
- **业绩前增持 = 强烈看好**
- **业绩后增持 = 信心确认**
- **业绩前减持 = 提前跑路**（强利空）
- **业绩后减持 = 套现**（中性偏空）

---

## 33.3 P33 实战判定

### Step 1: 内部人交易类型
```
IF 增持:
    P33 = "增持"
    → 看 Step 2
IF 减持:
    P33 = "减持"
    → 报告标注
```

### Step 2: 增持规模
```
IF 集体增持 (3+ 人):
    P33 = "集体增持"
    → 加仓提两档
ELIF 单人增持 > 100 万:
    P33 = "单人增持"
    → 加仓提一档
ELSE:
    P33 = "小额增持"
    → 加仓不调整
```

### Step 3: 时间窗口
```
IF 业绩公告前 30 日:
    P33 = "业绩前增持"
    → 信号最强
ELIF 业绩公告后 10 日:
    P33 = "业绩后增持"
    → 信号强
```

## 33.5 P33 与其他规则的关系

```
P18 风险股阻断
↓
P28 十大股东（持仓面）
↓
P33 内部人交易（动作面，领先信号）← V5.2.6 新增
↓
P25 股东户数（散户面）
↓
P27 融资融券
```

**P33 vs P28 互补**：
- P28 十大股东 = **看结果**（持仓变化）
- P33 内部人交易 = **看动作**（买卖信号）
- **P33 更领先**（动作早于结果）

---

## 33.6 P33 实战限制

- **频率低**：内部人增持/减持 1 年可能就几次
- **数据滞后**：公告日后 5-10 日才能查到
- **需要聚合**：必须按"公告日"聚合多人交易

**实战价值**：
- **频率低但准确度高**（内部人有信息优势）
- **强信号**应被 P14 组合管理 + P19 双引擎联合判定

---

## 33.7 P33 输出规范

报告必须包含：
```
【P33 内部人交易】
  近 12 个月内部人交易: X 笔
  增持: X 笔 / Y 总额
  减持: X 笔 / Y 总额
  集体增持 (3+ 人): [日期] 人数 X / 金额 Y 万 / 均价 Z
  内部人最新均价 vs 当前价: 涨/跌 X%
  判定: 集体增持 / 单人增持 / 持平 / 减持
  影响: 加仓信号调整 / 风险标注
```
