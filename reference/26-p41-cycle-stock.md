# P41 - 周期股反向信号

> **版本**: V5.2.9 新增
> **优先级**: P1
> **驱动案例**: 周期股主升浪（紫金矿业 +187.8% / 中国铝业 +123%）

## 一、问题背景

**周期股特性**：
- 行业月度跌 -5% 往往是**底部区域**（不是顶部）
- 行业月度涨 +3% 反而可能是**顶部**（追高风险）
- 周期股投资逻辑：**别人恐惧我贪婪**

**V5.2.8 缺失**：
- 没用行业属性区分周期股 vs 防御股
- 周期股按防御股规则处理 → 错失主升浪

## 二、规则定义

### 周期股清单

```python
CYCLE_INDUSTRIES = [
    '有色金属',  # 铜/铝/铅/锌
    '煤炭',      # 焦煤/动力煤
    '钢铁',      # 普钢/特钢
    '石油石化',  # 原油/炼化
    '基础化工',  # 化工原料
    '建筑材料',  # 水泥/玻璃
]
```

### P41 反向信号

```python
IF 行业 in CYCLE_INDUSTRIES:
    # 周期股专属加分（任何时候都生效）
    IF 行业月度 < -5%:
        # 行业下行 = 周期底部信号
        加分项:
            + 行业 Top 3 (P42): +1.5 或 +0.5
            + PE < 12: +1.5 (估值底)
            + 60 日振幅 > 35%: +1.0 (高弹性)
            + 央企持股 > 20%: +1.0 (稳定性)
        # 综合判断（总分 ≥ 4 进入"持有"或以上）
    
    ELIF 行业月度 > +5%:
        # 行业大涨 = 周期顶部信号（追高风险）
        减分项:
            - 周期股高位减分 -0.5
```

## 四、为什么周期股要反向

### 周期股的反向运动规律

```
行业月度 -10%  → 触底区（极佳买点）
行业月度  -5%  → 周期下行（关注）
行业月度   0%  → 平衡
行业月度  +5%  → 周期上行（追高风险）
行业月度 +10%  → 顶部区（警惕）
```

**关键洞察**：
- 周期股投资者应该在别人恐惧时贪婪
- 行业月度 -5% 到 -10% = 周期底部 = 最佳买点
- 行业月度 +5% 到 +10% = 周期顶部 = 应该减仓

### 周期股 vs 防御股

| 维度 | 周期股 | 防御股 |
|------|-------|-------|
| 行业 | 有色/煤炭/钢铁 | 公用/银行/医药 |
| 行业下行 | 底部信号（买） | 恶化信号（卖） |
| 行业上行 | 顶部信号（卖） | 利好信号（买） |
| 估值底 | 加分（与 P43 协同）| 加分 |
| 操作 | 反向操作 | 顺势操作 |

## 六、配套规则

- **P40v2 行业下行分级**：P41 在 P40v2 内部生效
- **P42 龙头识别**：配合 P41 加分
- **P43 估值底部**：P41 强触底信号之一
- **P44 三周期操作**：长周期 P41 触发后升级决策

## 七、注意事项

1. **P41 不是独立规则** - 嵌入 P40v2 内部
2. **周期股清单固定** - 6 个行业，不轻易扩展
3. **避免滥用** - 不能因为"觉得是底部"就硬买，必须满足多条件
4. **PE 估算** - 用 np_yoy 和历史 EPS 估算
