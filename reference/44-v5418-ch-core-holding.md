# 底仓型策略

> **当前版本归属**：V5.3.25 皇冠明珠加权版（三策略之一）
> **基础框架**：底仓变体（高量战法框架的"永不清仓"扩展）

> **V5.3.25 升级**：
> - 加皇冠明珠加权（STRICT 5y ROE ≥ 20% / RELAXED 5y ROE ≥ 15%）
> - 底仓永久持有股息税 0%（自动免税）
> - 商业判断软指标（行业地位/ROE 趋势/护城河/管理层）

> 永久持有的"压箱底"股票。闲钱定投，只等分红，基本不卖。

## 核心设计哲学

| 维度 | 短线 | 长线 | **底仓** |
|------|-------------|----------------|---------------------|
| **目标** | 短线机会 | 资本利得 | **分红现金流 + 复利** |
| **行业** | 任何启动期 | 成长/景气 | **稳健分红（银行/公用事业/消费）** |
| **仓位** | 7-17% | 15-25% | **30-50%（重仓）** |
| **加仓** | 浮盈顺势 | 不加仓 | **闲钱定投（自由）** |
| **减仓** | T+30 / 强平 | 分批止盈 | **基本不减仓** |
| **退出** | T+30 兜底 | 5 类恶化 | **永久恶化才走** |
| **盈利底线** | -5% 强平 | 浮盈 ≤ 0 清仓 | **不设底线（分红票浮亏正常）** |
| **持有期** | 几天-30 天 | 1-3 年 | **永久（5-10 年+）** |
| **收益来源** | 价差 | 价差 + 成长 | **股息 + 复利** |

## 一、建仓信号（3 个）

| 信号 | 阈值 | 数据源 |
|------|------|--------|
| 1. 股息率 | ≥ 4% | financial_data.dividend_yield |
| 2. ROE | ≥ 10% | financial_data.roe |
| 3. 行业稳定 | 金融 / 公用事业 / 必需消费 | 行业分类 |

**信号强度 → 仓位**：
- 3 信号齐：**50%**（重仓）
- 2 信号：**35%**
- 1 信号：**20%**
- 0 信号 → 不建仓

**典型标的**：
- 银行股：交通银行、农业银行、工商银行
- 公用事业：长江电力
- 必需消费：贵州茅台（注意：茅台更多是长线而非底仓）

## 二、仓位规则

| 规则 | 阈值 | 说明 |
|------|------|------|
| 单票上限 | 50% | 底仓可以重仓一只 |
| 总仓位上限 | 80% | 留 20% 现金 |
| 行业集中度 | ≤ 70% | 允许银行/公用事业集中 |
| 现金保留 | 20% | 永远留现金应急 |

## 三、加仓规则（**不定时**，有闲钱买点 ⭐⭐⭐）

### 1. 不定时加仓（用户原话"有闲钱时买一点，不定时的"）

```python
# 任何时间、任何价格、任何金额（用户自由）
python3 portfolio_manager.py add 601328.SH 7.05 1000 '有闲钱买点'
```

**特点**：
- **不定时**（不是定投，没有固定频率）
- **不择时**（不追涨不杀跌）
- **不等待信号**（无信号也能加）
- **完全自由**（用户自主）

**与定投的区别**：

| 模式 | 频率 | 金额 | 触发 |
|------|------|------|------|
| 定投 DCA | 固定（每月/每季）| 固定 | 时间 |
| **不定时加仓** | **不固定** | **不固定** | **有闲钱** |

### 2. 下跌加倍（股息率 > 6%）

```python
# 如果股息率 > 6%（银行股破净常见），建议加倍买
python3 portfolio_manager.py add 601328.SH 6.50 2000 '股息率>6% 加倍买'
```

**逻辑**：
- 股息率 = 每股分红 / 当前价
- 价格越低 → 股息率越高 → 越值得买
- 下跌 = 打折买入机会

### 3. 分红再投资

```python
# 每年分红到账 → 自动再投资
python3 portfolio_manager.py add 601328.SH 7.20 500 '2025 年分红再投'
```

**效果**：
- 复利效应：分红再投资 → 更多股数 → 更多分红
- 5 年复利：年化 +5% 股息 + 5% 分红再投 ≈ +10%

## 四、退出条件（永久恶化才走 ⭐⭐⭐）

### 1. 永久恶化（**唯一退出条件**）

| 类型 | 描述 |
|------|------|
| 公司破产 | 进入破产程序 |
| 退市 | 强制退市 |
| 接管 | 被监管接管（如包商银行） |
| 行业系统性风险 | 银行业崩盘 / 公用事业改革 |
| 政策永久性变化 | 银行被国有化 / 取消分红 |

**操作**：清仓（**不再买入**）

### 2. **基本不减仓**（核心仓逻辑）

- 浮亏 10%？**不卖**（分红票浮亏正常）
- 浮亏 30%？**不卖**（继续等分红摊薄成本）
- 跌破净资产？**反而加仓**（打折买入）
- 高管减持？**不卖**（与分红逻辑无关）
- 短期负面新闻？**不卖**（无影响）

### 3. 永不止盈

- 浮盈 +50%？**继续持有**（让复利）
- 浮盈 +100%？**继续持有**（分红基数变大）
- 历史新高？**继续持有**（分红的最佳状态）

## 五、监测频率

| 监测项 | 频率 | 来源 |
|--------|------|------|
| 分红预案 | 每年 3-4 月 | dividend 表 |
| 分红到账 | 每年 6-7 月 | 银行流水 |
| 经营基本面 | 每年 3/8 月 | financial_data（年报/半年报）|
| 行业系统性风险 | 持续 | 新闻 + 监管动态 |
| 公司治理 | 持续 | 公告 |

**关键**：不监测短期价格、量能、形态（**与底仓逻辑无关**）。

## 六、决策树

```
底仓型每日 review
    ↓
1️⃣ 公司永久恶化（破产/退市/接管）?
    → YES: 🔴 清仓（不再买入）
    → NO:  继续 ↓
    ↓
2️⃣ 行业系统性风险?
    → YES: 🔴 清仓
    → NO:  继续 ↓
    ↓
3️⃣ 分红正常发放?
    → YES: 🟢 持有 + 累计分红
    → NO:  🟡 监测（可能不卖）
    ↓
4️⃣ 股息率 > 6%（打折中）?
    → YES: 🟢 加仓候选（建议加倍）
    → NO:  持有
    ↓
5️⃣ 有闲钱?
    → YES: 🟢 定投买点
    → NO:  持有
```

## 七、组合配置

### 三策略组合（用户当前）

| 角色 | 标的 | 策略 | 仓位 | 持有期 |
|------|------|------|------|--------|
| **核心仓** | 交通银行 | 底仓 | 50% | 永久 |
| **卫星仓** | 立讯精密 | 短线 | 17% | 几天-30 天 |
| 现金 | - | - | 33% | 应急 |

### 进一步扩展

如果再加 1-2 只底仓 + 1-2 只长线：

| 角色 | 标的 | 策略 | 仓位 |
|------|------|------|------|
| **核心仓 1** | 交通银行 | 底仓 | 30% |
| **核心仓 2** | 长江电力 | 底仓 | 20% |
| **成长仓** | 贵州茅台 | 长线 | 20% |
| **短线仓** | 立讯精密 | 短线 | 13% |
| 现金 | - | - | 17% |

**总收益结构**：
- 底仓（50%）：年化 5-8%（股息 + 复利）
- 长线（20%）：年化 10-15%（资本利得）
- 短线（13%）：年化 15-25%（价差，但波动大）
- 现金（17%）：0%

**整体年化预期**：8-12%（稳健）

## 八、实战案例

### 案例 1：交通银行（典型底仓）

**初始**：
- 建仓时间：2024-03-15
- 成本：7.00 元 × 10000 股 = X 元
- 仓位：50%

**2024 年分红**：
- 每股分红：0.X 元（含税）
- 税后：0.X 元
- 收到分红：X 元
- 再投资：3,380 / 7.20 = 469 股（按现价）
- 新持股：10,469 股

**2025 年分红**：
- 股数：10,469 股
- 每股分红：假设 0.40 元
- 收到分红：X 元
- 再投资：4,188 / 7.50 = 558 股
- 新持股：11,027 股

**5 年后**：
- 假设股价不变 7.50 元
- 总股数：约 13,500 股（年化 +6%）
- 价值：X 元
- 累计分红：约 X 元（5 年）
- **总收益**：+45%（4.5 万 / 7 万）

**关键**：5 年不动，年化 7.7%（**含分红再投**）。

### 案例 2：长江电力（公用事业底仓）

**特点**：
- 现金流稳定（长江三峡）
- 股息率 3.5-4%
- 行业垄断（几乎没有新进入者）
- 适合做底仓

**预期**：
- 年化 4-5% 股息 + 2-3% 复利 = 6-8% 年化

## 十、与 高量战法 / 长线 的根本差异

| 决策 | 短线 | 长线 | 底仓 |
|------|------|------|------|
| 浮盈 +20% | 减仓 25% | 减仓 25% | **继续持有** |
| 浮亏 -10% | 强平 | 清仓 | **继续持有** |
| 浮亏 -30% | 强平 | 清仓 | **加仓（打折买入）** |
| 跌破 MA5 | 减仓 | 减仓 | **不关心** |
| T+30 | 清仓 | 继续 | **继续** |
| 股价新高 | 减仓 | 继续 | **继续** |
| 持续下跌 | 减仓 | 减仓 | **加仓** |
| 公司利空 | 减仓 | 清仓 | **监测** |

**核心差异**：底仓型**反向**——别人减仓时加仓。
