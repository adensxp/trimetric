## 7. V5.2.7 P33 实战操作要点

1. **金额是关键** = 内部人交易金额 > 50 亿 是显著信号
2. **集体性是核心** = 1 人交易 < 5 人集体 < 央企集团联合
3. **方向决定意义** = 增持正面 / 减持负面
4. **价格是验证** = 减持价格低 / 增持价格高 = 真实信号
5. **业绩期同步** = 业绩底部增持 = 真实信号
6. **协议转让特殊** = 央企间协议转让 = 资源整合
7. **战略股东清仓** = 战略合作终止，但价格提供支撑
8. **AI 龙头减持** = 估值高位信号，需结合业绩
