# P45 操作链止损止盈（V5.3.7）

## 一、3 大新规则

### 规则 #1：P45 止损线
- **触发条件**：T+5 ret < -5%
- **操作**：减仓 30%（剩余 70% 持有到 T+N）
- **保护对象**：短线快速下跌票

### 规则 #2：P45 止盈线
- **触发条件**：T+30 ret > 20%
- **操作**：减仓 50%（剩余 50% 持有到 T+N）
- **锁利对象**：中期主升浪

### 规则 #3：2 年 ret 减仓信号
- **触发条件**：行业 2 年 ret < -15%
- **操作**：决策组"减仓"（替代持有）
- **避免**：行业持续下跌被错杀

## 三、P45 操作链逻辑

```
建仓 100%
T+5: 如 ret < -5% → 减仓 30%（剩余 70% 持有到 T+N）
T+30: 如 ret > 20% → 减仓 50%（剩余 50% 持有到 T+N）
否则：100% 持有到 T+N
```

- T+30 止盈触发：168 次（10.0%）
