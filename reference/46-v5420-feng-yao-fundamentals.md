## 🎯 升级驱动

V5.3.19 实战发现：**V5.3.18-LT 缺少财务硬过滤**——只看了 ROE/营收/行业/龙头/估值，缺少微淼方法的"好公司"硬指标（净现金含量/毛利率/资产负债率/分红比例）。

**实战教训**：立讯精密 V5.3.18 短线 -267.56 元，**如果用微淼方法论筛选，根本不会建仓**（立讯精密 45 分 D 级）。

## 📊 8 条新规则详解

（**R059-R066 共 8 条**，不是 6 条）

### R059: LT 建仓 6: 股息率 ⭐⭐⭐

```python
description: 动态股息率 > 10 年期国债收益率
数据源: dividend + bond_yield
触发: 加仓信号（独立于 R015 估值规则）
```

**实战应用**：
- 2026 年 10Y 国债收益率约 2.7%
- 个股动态股息率 = 上年度股息 / 当前价
- 例：交通银行股息 0.376 / 7.20 = 5.22% > 2.7% ✅

### R060: LT 风控: 现金流过滤 ⭐⭐

```python
description: 经营性现金流 / 净利润 > 0.8
数据源: financial_data.OCF / NP
触发: 任一不达标 = 淘汰（V5.3.20 选 A）
```

**实战应用**：
- 净利润 1 亿元，但经营现金流只有 6000 万 → 0.6 < 0.8 = 淘汰
- 这是**最有效的"防造假"指标**

### R061: LT 卖出: 股息率过低 ⭐⭐⭐

```python
description: 动态股息率 < 10Y 国债 / 3
数据源: dividend + bond_yield
触发: 卖出候选（微淼卖出 ②）
```

**实战应用**：
- 10Y 国债 2.7% / 3 = 0.9%
- 个股动态股息率 < 0.9% → 卖出
- 例：海天味业 0.95% > 0.9%（不卖）/ < 0.9% → 卖

### R062: LT 风控: 毛利率 ⭐⭐

```python
description: 连续 5 年毛利率 > 40%
数据源: financial_data.gross_margin
触发: 任一不达标 = 淘汰
```

**实战应用**：
- 茅台 91.5% ✅ / 立讯精密 18% ❌（直接淘汰）
- 反映产品护城河（杜邦分解：高毛利 > 高周转 > 高杠杆）

### R063: LT 风控: 资产负债率 ⭐⭐

```python
description: 连续 5 年无一年资产负债率 ≥ 60%
数据源: financial_data.debt_ratio
触发: 任一不达标 = 淘汰
```

**实战应用**：
- 茅台 19% ✅ / 银行 92% ❌（银行除外，用 V5.3.18-CH）
- 反映偿债风险 + 大股东可能伤小股东

### R066: LT 卖出: 有更好机会 ⭐⭐

```python
description: 发现明显更优投资机会（如红利 ETF 6% > 当前 2%）
数据源: 对比标的
触发: 跨标的切换（卖出 ④）
```

**实战应用**：
- 红利 ETF 分红率 6% > 当前持仓 0.86% → 切换
- 但**短线不适用**（短线没耐心等 ETF）

### R064: LT 风控: 分红比例 ⭐⭐

```python
description: 分红比例 > 25%
数据源: financial_data.dividend_ratio
触发: 任一不达标 = 淘汰
```

**实战应用**：
- 茅台 52% ✅ / 立讯精密 15% ❌
- 反映公司厚道程度（封老师认为：分红能力 = 业绩真实性）

### R065: LT 风控: 上市年限 ⭐⭐

```python
description: 上市 > 3 年
数据源: stock_info.list_date
触发: 任一不达标 = 淘汰
```

**实战应用**：
- 茅台 23 年 ✅ / 立讯精密 12 年 ✅
- 避免 IPO 化妆术（很多公司上市后业绩变脸）

## 💡 关键洞察

### 1. 微淼方法论验证有效 ⭐⭐⭐

- 茅台 90 分 A 级（微淼标准）
- 实战中立讯精密 D 级被过滤掉（**短线玩法不符合长线标准**）
- 银行股 D 级但适合底仓玩法（**不同策略用不同过滤**）

### 2. 解决了 V5.3.18-LT 的"软指标"问题

- 之前只有"ROE ≥ 15%"等 5 个宽信号
- 现在加了 6 个微淼硬指标（净现金含量/毛利率/资产负债率/分红比例/上市年限/股息率）
- **任一不达标 = 淘汰**（严了，但不严到错过机会）

### 3. 互补而非替代

- 微淼方法论补充 V5.3.18-LT 的**财务硬过滤**
- 不替代 V5.3.18 短线的**形态+量价**（那是技术面）
- 也不替代 V5.3.18-CH 底仓的**R037-R039**（银行股特性）
