# P23 · 高量日资金流验证（AStockCashFlow · V5.2.4 新增）

> **背景**：V5.2.3 实战中际旭创暴露——**单纯"放量+收阳"不足以判定高量有效**。8-05 振 10.1%、量 7232 万股、收阳 +7.7%——按 V5.2.3 规则是"绝对高量"，但资金流 DDE -1.35 亿（主力净流出）。**8-04 真高量，8-05 是真高量但已是主力出货信号**。
>
> **数据源**：恒生 `AStockCashFlow`（特大单+大单净买入 DDE / 资金比 / 涨跌幅 / 连红天数）

---

## 23.1 触发条件

V5.2.3 高量规则**继续有效**，但叠加 P23 资金流二次验证。

**V5.2.4 升级**：
1. **V5.2.3 判定高量日**（量 > 前 3 日 max）
2. **查 `AStockCashFlow` 取该日及前 5 日 DDE 数据**
3. **运行 P23 验证**：
   - 高量日 DDE > 0 → **真高量**（主力进攻）
   - 高量日 DDE ≤ 0 → **量价背离**（主力出货嫌疑）
4. **背离时降级处理**（见 23.3）

## 23.2 DDE 解读

| DDE（特大单+大单净买入，万元） | 解读 | 信号 |
|------------------------------|------|------|
| > +1 亿 | **主力强进攻** | 高量 + DDE 双确认，最强 |
| 0 ~ +1 亿 | 主力小幅净流入 | 标准高量 |
| -1 亿 ~ 0 | 主力小幅净流出 | **量价背离**，降半级使用 |
| < -1 亿 | **主力强出货** | **量价严重背离**，高量失效 |

> **阈值 -1 亿元 = "10 日均成交额 × 5%"** 的经验值，可按品种调整：
> - 高股息长线票：阈值放宽到 -2 亿
> - 高波动科技股：阈值收紧到 -0.5 亿

## 23.3 量价背离时的处理

### 场景 1：高量日 DDE 在 -1 亿 ~ 0（轻度背离）
```
- 高量信号降半级
- 三天定性：T+1/T+2/T+3 任一收 < 实体低 → 触发 C3
- 三天定性：全部站上实体低 → 高量仍有效
```

### 场景 2：高量日 DDE < -1 亿（严重背离）
```
- 高量信号失效
- 直接按"无明确主力痕迹"处理
- 启动"二次确认机制"：
  - 3 日内出现新高量且 DDE > 0 → 重新激活原高量
  - 3 日内未出现 → 高量彻底失效，按无高量处理
```

### 场景 3：连续 2 日高量且 DDE 都 ≤ 0
```
- **主力出货嫌疑强烈**
- P23 直接标 "出货" 状态
- 报告必须输出："高量信号失效，主力疑似出货"
- 不进入 B 加仓信号判定
```

## 23.4 P23 实战流程

```python
def verify_high_volume_with_cashflow(date, kline_data, cashflow_data):
    """V5.2.4 P23 资金流验证"""
    
    # Step 1: 判定是否高量日（V5.2.3 规则）
    if not is_high_volume_day(date, kline_data):
        return "non_high_vol", None
    
    # Step 2: 取当日 DDE
    dde = cashflow_data[date]["特大单+大单净买入"]
    
    # Step 3: 验证
    if dde > 10000:  # +1 亿
        return "valid_strong", dde
    elif dde > 0:
        return "valid_standard", dde
    elif dde > -10000:  # -1 亿
        return "divergence_mild", dde
    else:
        return "divergence_severe", dde
```

| 日期 | V5.2.3 高量 | DDE（万）| P23 判定 | 调整 |

- **P23 单独判定"8-10 真出货"，但 P21 + P23 联合判定"假破位"**（见 P21 v2 升级）
