## 20.12 P9·板块自适应阈值（V5.2.0 扩展）

> **解决问题**：V5.2.0 P1 阈值（股息率>4%、振幅<3%）按银行股标准制定，搬到消费/医药/科技/资源等板块失灵
> **解决方案**：按申万一级行业分类（6 大类）设定自适应 P1 阈值
> **编写依据**：601328 交通银行 + 4 大行 + 茅台/长电/神华/伊利等 10 标的实战验证
> **验证结果**：V5.2.0 识别率 40% → P9 识别率 70%（+75%）

### 20.12.3 P9 与 P1 的关系

| 场景 | V5.2.0 P1 | P9 修订 P1 | 备注 |
|------|-----------|-----------|------|
| 银行股（工行/建行/招行/交行）| 阈值 4% | 阈值 4% | **一致** |
| 公用事业（长江电力）| 阈值 4% | **阈值 3%** | P9 修复 |
| 资源周期（中国神华）| 阈值 4% | **阈值 2.5%** | P9 修复 |
| 必选消费（贵州茅台/伊利）| 阈值 4% | **阈值 1.5%** | P9 修复 |
| 可选/科技（中际旭创）| 阈值 4% | **阈值 0.5%** | P9 修复 |
| 其他 | 阈值 4% | **阈值 2%** | P9 修复 |

**P9 决策原则**：
- 标的**先按申万行业查表**得到自适应阈值
- 用自适应阈值替代 P1 固定阈值（股息率>4%、振幅<3%）
- P2-P8 **完全沿用 V5.2.0**（不需要修改）
- P1 通过后，P2-P8 路径与 V5.2.0 相同

### 20.12.6 边界案例与未来扩展

1. **紫金矿业（周期蓝筹）**：当前 P9 仍判 ❌（股息率 1.85% < 2.5%）
   - 解决：RESOURCE 下增加"周期蓝筹子分类"（股息率 ≥ 1.5% 即可）

2. **恒瑞医药（创新药龙头）**：当前 P9 仍判 ❌
   - 解决：医药下细分"创新药/中药/医疗器械/医药商业"子分类

3. **行为特征缺失**：
   - 当前只用财务特征（股息率、振幅、市值、分红）
   - V5.3 应加入：北向资金持股占比、机构持股比例、ETF 成分股、AH 股溢价

### 20.12.7 P9 实施清单

- [ ] 跟踪 P9 实战有效性（建议 3-6 个月）

### 20.12.8 P9 风险提示

1. **行业分类边界**：申万一级行业只有 34 个，二级/三级更精细但需要手动下沉
2. **股息率时效性**：TTM 股息率每天变化，建议每日复盘
3. **回测不充分**：仅 10 标的样本验证，建议扩大样本到 100+ 标的
4. **行为特征未纳入**：纯财务特征可能在熊市/牛市失真
5. **新股不适用**：上市 < 3 年的标的 div_years 不达标
6. **风险股阻断**（强制）：ST / *ST / 退市 / B 股直接阻断分析，不进入 P1-P9 判定

### 20.12.9 风险股阻断规则（强制前置）

**触发条件**（任一满足即阻断）：

| 风险类型 | 识别特征 | 阻断等级 |
|----------|----------|----------|
| **\*ST 退市风险** | 股票名含 "*ST" | 🔴 最高 |
| **ST 风险警示** | 股票名以 "ST" 开头或含 " ST" | 🟠 高 |
| **退市整理期** | 股票名含 "退" / "退市" / 以"退"结尾 | 🔴 最高 |
| **B 股** | 代码以 200 / 900 开头 | 🟡 中 |

**执行**：
- **直接阻断** P1-P9 全部判定流程
- 输出风险等级 + 阻断原因 + 严禁买入建议
- 不计算技术指标、不应用基本面阈值

**实战理由**：
- ST/*ST 股流动性极差，常出现连续跌停
- 退市股最后交易日摘牌，买入即归零
- B 股市场规则不同、估值逻辑不同、流动性差
- V5.2.0 6.1 节"无 ST 风险"前提的硬约束

**代码实现**：见 `p9_engine.py` 的 `check_risk_stock()` 函数
