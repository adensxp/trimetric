# P40v2 - 行业下行分级判断

> **版本**: V5.2.9 新增（替代 V5.2.8 P40）
> **优先级**: P0（与 P18 并列强制前置）
> **驱动案例**: 601600 中国铝业 3 年回测（错失 +123%）

## 一、问题背景

**V5.2.8 P40 规则**：
```
IF 行业月度 ≤ -5%:
    → 🔴 卖出（强制触发）
```

**V5.2.8 回测问题**（30 行业龙头 2023-08-17 决策日）：
- 26/30 票被强制卖出
- 9 票错失主升浪（紫金矿业 3 年 +187.8%）
- 综合准确率 35.6%

**根因**：V5.2.8 P40 没区分"周期下行"与"结构恶化"。

## 二、规则定义

### V5.2.9 P40v2

```python
# 触发条件：行业月度 ≤ -5%
IF 行业月度 ≤ -5%:
    # 情况 1：强触底信号（行业下行 + 龙头 + 估值底 + 周期股 + 高弹性）
    IF 票是行业 Top 3 AND PE < 12 AND 行业 in 周期股 AND 60日振幅 > 35%:
        → 🟢🟢🟢🟢 买入（强触底，V5.2.9.2 新增）
    
    # 情况 2：触底信号（行业下行 + 龙头 + 估值底 + 周期股）
    ELIF 票是行业 Top 3 AND PE < 12 AND 行业 in 周期股:
        → 🟢🟢🟢 持有（触底）
    
    # 情况 3：行业龙头（非触底）
    ELIF 票是行业 Top 3:
        → 🟡🟡 减仓（观望）
    
    # 情况 4：非龙头
    ELSE:
        → 🔴 卖出（结构性问题）
```

### 周期股行业清单

```
['有色金属', '煤炭', '钢铁', '石油石化', '基础化工', '建筑材料']
```

## 四、为什么这样改

### 周期股 vs 结构性行业

| 类型 | 行业 | 行业下行含义 | 操作 |
|------|------|------------|------|
| **周期股** | 有色/煤炭/钢铁/石油/化工/建材 | 周期底部 = 买入机会 | 触底加分 |
| **结构性问题** | 房地产/美容/传媒/社服 | 政策/消费/需求结构问题 | 卖出 |

### 估值底 + 龙头 = 强触底三件套

```
强触底 = 行业下行（月<-5%）
       + 行业 Top 3（资金抱团）
       + PE<12（估值便宜）
       + 60 日振幅 > 35%（高弹性）
       + 周期股（反转动能）
```

## 六、注意事项

1. **PE 估算**：用 np_yoy 和历史 EPS 估算 PE（数据库无直接 PE 字段）
2. **龙头识别**：用 `rank_in_industry` 字段（1 = 绝对龙头）
3. **强触底是 P40v2 的最严条件**：5 个条件全满足才触发
4. **房地产/美容等不触发强触底**：因为不在周期股清单

## 七、配套规则

- **P41 周期股反向**：进一步强化周期股识别
- **P42 龙头识别**：Top 1-3 加分（基础）
- **P43 估值底部**：PE<12 加分（基础）
- **P44 三周期操作**：长周期 P40v2 决策升级
