# P26 · 风险因子增强（StockRiskFactorReport · V5.2.4 新增）

> **背景**：V5.2.3 P18 风险股阻断**只检查 ST/*ST/退市/B 股**。实战中**"看似正常但隐藏风险"**的票无法识别——比如 8-10 暴跌当天动量因子从 4.3 跌到 0.7（动量消失）+ 价值因子 -1.5（极低估），都是结构性风险信号。
>
> **数据源**：恒生 `StockRiskFactorReport`（10 个风险因子，基准为中证全指 000985）

---

## 26.1 风险因子体系

恒生风险因子是基于中证全指 000985 归一化的 10 个因子：

| 因子 | 含义 | 解读方向 |
|------|------|----------|
| **价值因子** | PE/PB/PCF 等估值水平 | **负值大 = 极度低估**（如 -1.5）|
| **成长因子** | 营收/净利润增速 | **正值大 = 高成长**（如 +2.8）|
| **质量因子** | ROE/ROA/经营现金流 | **正值大 = 高质量**（如 +1.1）|
| **动量因子** | 近期涨跌幅趋势 | **正值大 = 强势动量**（如 +4.3）|
| **波动因子** | 历史波动率 | 正值大 = 高波动 |
| **市值因子** | 流通市值 | 正值大 = 大盘股 |
| **流动性因子** | 日均成交额/换手率 | 正值大 = 高流动性 |
| **分红因子** | 股息率 | **负值大 = 低分红** |
| **情感因子** | 新闻/舆情/研报关注度 | **正值大 = 高关注**（如 +11）|

> **所有因子已对中证全指归一化**，可跨股票横向比较。

## 26.2 P26 关键信号

### 26.2.1 动量因子突变

```
IF 动量因子 5 日内跌幅 > 50%:
    动量消失信号
    → 报告标注, 加仓信号降一档
```

**实战案例（中际旭创 8-04 ~ 8-10）**：
| 日期 | 动量 | 变化 |
|------|------|------|
| 8-04 | **4.30** | 极强动量 |
| 8-05 | 1.97 | -54% |
| 8-06 | 2.07 | -52% |
| 8-07 | 1.33 | -69% |
| 8-10 | **0.69** | -84% |
| 8-11 | 1.04 | -76% |
| 8-12 | 1.56 | -64% |
| 8-14 | 2.55 | -41% |

**8-04 极强动量 → 8-10 动量消失 = 顶部确立信号**
但 8-11~8-14 动量回升 → 主力在重新加仓

### 26.2.2 情感因子极端值

```
IF 情感因子 > 10:
    极端高关注 = 散户大量涌入 = **顶部信号**
    
IF 情感因子 < 1:
    关注骤降 = **底部信号**（关注度跌无可跌）
```

**实战案例（中际旭创）**：
- 8-07 情感因子 **11.30**（10 天最高）= **极端高关注 = 顶部信号**
- 8-11 情感因子 **1.20**（暴跌后）= **底部信号**
- **8-07 顶部信号 + 8-11 底部信号 = "假破位" 验证**

### 26.2.3 价值因子负值大

```
IF 价值因子 < -1.5:
    极度低估 = **安全垫**
    加仓信号提一档
```

**实战**：中际旭创价值因子 -1.48 ~ -1.74（**持续极低估**），与 PB 31 矛盾？
- 实际：价值因子基于**滚动 PE 历史百分位**（低 PE 因子 = 历史百分位低）
- 当前 PE TTM 73.79 看似高估，但**历史百分位**（过去 5 年）可能是**低位**
- 这与 P19 PE 分位 4 方案目标一致

### 26.2.4 多因子综合判定

```
正常状态: 至少 3 个因子在 ±1 范围内
异常状态: 5+ 因子极端 → 报告必须标注"多因子异常"
```

## 26.3 P26 与 P18 的关系

P18 风险股阻断 = **硬阻断**（ST/退市/B 股/违规 → 不可分析）
P26 风险因子 = **软警告**（动量消失/情感极端 → 加分项调整，不阻断）

**优先级**：
- P18 阻断 → 跳过 P26
- P26 警告 → 继续分析但带警告标记

## 26.4 P26 实战判定流程

```python
def check_risk_factors(stock_code, days=10):
    """P26 风险因子综合判定"""
    factors = get_risk_factor_report(stock_code, days)
    
    warnings = []
    if factors["动量因子"].pct_change().iloc[-1] < -0.5:
        warnings.append("动量消失")
    if factors["情感因子"].iloc[-1] > 10:
        warnings.append("极端高关注")
    if factors["价值因子"].iloc[-1] < -1.5:
        warnings.append("极度低估")
    
    return warnings
```
