# P30 · 分红连续性信号（BonusStock · V5.2.5 新增）

> **背景**：V5.2.3 P13 长线机构票判定硬条件"**连续分红 > 5 年**"，但实战中**从未系统取过 BonusStock 数据**。V5.2.5 实战比亚迪连续 4 年高分红（20%~30%）证实是真长线票；中际旭创虽高增长但分红率极低（< 1%），从分红角度看不是长线票。
>
> **数据源**：恒生 `BonusStock`（分红方案 / 每股股利 / 分红率 / 股本基准日 / 实施进度）

---

## 30.1 分红基础

| 概念 | 含义 |
|------|------|
| 每股股利（税前）| 每 10 股派多少元（如 10 派 3.58 = 每股 0.X 元）|
| 分红率 | 当年分红总额 / 当年净利润 = **股利支付率** |
| 股息率 TTM | 当前股价 / 过去 4 个季度分红 = **持仓收益率** |
| 连续分红年数 | 连续每年都分红的年数 |

---

## 30.2 P30 关键信号

### 30.2.1 连续分红年数（P13 长线机构票硬条件）

| 连续年数 | P13 判定 | 实战信号 |
|---------|---------|---------|
| **≥ 5 年** | ✓ 长线机构票候选 | 高质量 |
| 3-4 年 | △ 待观察 | 中等 |
| 1-2 年 | ✗ 不构成连续 | 低 |
| 0 年（不分红）| ✗ 排除长线 | **成长股特征** |

### 30.2.2 分红率稳定性

| 5 年分红率标准差 | 解读 | 信号 |
|-----------------|------|------|
| **< 5%** | **稳定分红** | 长线资金最爱 |
| 5-10% | 较稳定 | 标准 |
| 10-20% | 不稳定 | 关注 |
| **> 20%** | **大幅波动** | 警示（可能业绩不稳）|

### 30.2.3 股息率 TTM

| 股息率 TTM | P30 判定 |
|-----------|---------|
| **> 5%** | **高息**（含 P2 高股息保护触发）|
| 3-5% | 中等 |
| 1-3% | 低 |
| **< 1%** | **不分红 / 极低**（成长股特征）|

---

## 30.3 P30 实战判定流程

### Step 1: 连续分红年数
```
连续年数 = count(if 每年的分红方案进度 = "方案实施")
IF 连续年数 ≥ 5:
    P30 = "长线机构票分红条件满足"
    → 强化 P13 判定
```

### Step 2: 分红率稳定性
```
5 年分红率标准差
IF < 5%:
    P30 = "稳定分红"
IF > 20%:
    P30 = "分红率大幅波动"
    → 报告标注
```

### Step 3: 股息率 TTM
```
IF 股息率 TTM > 5%:
    P30 = "高股息"
    → 触发 P2 高股息保护（仓位上限 40% → 70%）
```

## 30.4 实战案例

### 比亚迪 002594（2022-2025 分红）

| 年度 | 每股股利(税前) | 分红率 | 连续年数 |
|------|---------------|--------|---------|
| 2025 | 0.358 | 10.01% | 4+ |
| 2024 | 3.974 | 30.00% | 3+ |
| 2023 | 3.098 | 30.00% | 2+ |
| 2022 | 1.142 | 20.00% | 1+ |

**P30 判定**：
- 连续 4 年高分红（**接近 P13 5 年硬条件**）
- 分红率 10-30%（中等但不稳定）
- 股息率 TTM 1.49%（中等）

**实战意义**：
- 比亚迪 **勉强算"近长线"**（连续 4 年）
- 但分红率 30% > 20% 标准 → **不稳定**
- **建议观察 1-2 年再判定长线**

### 中际旭创 300308

中际旭创历史分红数据：暂未在返回结果中看到（按 stockObject 排序优先返回比亚迪），**需要单独查询**。
- 已知股息率 TTM 0.10%（**极低**）
- 主营业务为高增长 AI 光模块（**典型成长股**）
- **P30 判定：不分红或极低分红 = 明确非长线机构票**

### 贵州茅台 600519

| 年度 | 每股股利(税前) | 分红率 | 股息率 TTM |
|------|---------------|--------|-----------|
| 2024 | 30.88 (估) | 75%+ | 3.85% |
| 2023 | 30.88 (估) | 75%+ | - |

**P30 判定**：
- 茅台 **持续高分红**（行业典型）
- 股息率 TTM 3.85% = **接近 P2 高股息保护阈值 5%**（按 V5.2.3 阈值 4% 已达）
- **典型长线机构票**（P13 4 条标准可能全部满足）

## 30.5 P30 与 P13 联动

P13 长线机构票判定 = **P30 + 9 个其他条件**：

| P13 条件 | P30 角色 |
|---------|---------|
| 流通市值 > 1000 亿 | - |
| 60 日振幅 < 3% | - |
| **股息率 > 4%** | **P30 验证** |
| **连续分红 > 5 年** | **P30 验证** |

**P30 是 P13 第 3、4 条的硬数据支撑**——之前都是估算，现在用 BonusStock 真实数据。

## 30.6 P30 输出规范

报告必须包含：
```
【P30 分红信号】
  连续分红年数: X 年
  近 5 年分红率范围: X% ~ Y%
  分红率标准差: X%
  历年每股股利: [2022: 1.14, 2023: 3.10, 2024: 3.97, 2025: 0.36]
  股息率 TTM: X%
  判定: 稳定高分红 / 不稳定 / 极低
  P13 联动: 满足 / 不满足 / 部分满足
```

## 30.7 P30 与其他规则的关系

```
P18 风险股阻断
↓
P13 长线机构票（P30 是关键支撑）← V5.2.5 P30 强化
↓
P9 板块自适应
↓
P30 分红连续性（长线硬条件）← V5.2.5 新增
↓
P2 高股息保护（仓位上限 40% → 70%）
```

**P30 触发时**：
- 连续分红 ≥ 5 年 + 股息率 > 4% → P13 长线机构票判定**强信号**
- 连续分红 < 3 年 → P13 判定**排除**
