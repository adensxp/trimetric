## 🔁 执行流程

### 1️⃣ 运行质量扫描
bash: cd /workspace/stock_db && python3 quality_monitor.py

### 2️⃣ 检查警报（candidates.db 的 quality_alert_log 表）
```python
import sqlite3
conn = sqlite3.connect('/workspace/stock_db/candidates.db')
rows = conn.execute("SELECT stock_code, stock_name, alert_type, severity, prev_value, current_value, action FROM quality_alert_log WHERE trade_date = date('now','localtime') ORDER BY severity").fetchall()
for r in rows:
    print(r)
conn.close()
```

### 3️⃣ 报告规则
- `severity=critical`（W19 A→C 降级 / W16 红旗新触发）→ **立即向用户报告**：股票、警报类型、前值→现值、建议动作（减仓 50% 或清仓）
- `severity=high`（A→B / B→C / 护城河丢失）→ 汇总报告，建议减仓 30%
- `severity=medium`（ROE 跌破 12%）→ 汇总列出

- 按严重度分级的警报清单
